## 一、MASS 反转预警扫描（多周期）

全市场扫描「当前正处于 Mass Index（MI）反转预警窗口——凸起已形成、尚未回落确认」且「处于多头/上升趋势」的标的。MASS 口径与 K 线主图的琥珀色预警竖带完全一致：自适应进入线 = 自身 MI 历史 P90（钳制在 24~31），离开线 = 进入线 − 0.5；趋势口径复刻趋势扫描的 5 路证据等权计分。

### 1.1 入口与参数

入口：信号监控面板 → 「**MASS预警扫描**」页签。

| 参数 | 可选值 | 默认 | 说明 |
|------|--------|------|------|
| 市场范围 | 沪市 / 深市 / 北交所（多选） | 不选 = 全部 | 缩小扫描范围 |
| 板块细分 | 主板 / 创业板 / 科创板 / 北交所（多选） | 不选 = 全部 | 精确到板块过滤 |
| K线周期 | 日K / 60分 / 30分 / 15分 / 5分 / 1分 / 周K | 日K | 同一指标在不同周期下独立扫描预警窗口 |
| 趋势指标自选 | 多头排列 / MA20上行 / Supertrend翻多 / ADX强多头 / 通道上半区（多选） | 不选 = 全部 5 路参与计分 | 只勾选关注的证据，其余不参与计分 |
| 趋势过滤 | 满足 ≥1（宽松）/ ≥2 / ≥3（标准）/ ≥4 / 全部满足 | ≥3 | 在自选指标范围内按满足个数过滤（后端自动钳制到自选个数） |
| 进入预警根数 | 不限 / 刚进入 1~3 / 4~7 / 8~15（持续预警）/ 15 以上（长期预警） | 不限 | 从 MI 越过进入线那根起算。计数单位跟随周期：日K = 天、周K = 周、分钟 = 根 |

### 1.2 使用步骤

1. 打开信号监控面板，切到「MASS预警扫描」页签；
2. 按需设置市场范围、板块细分、K线周期；
3. 自选趋势指标并选择过滤档位（不选指标 = 默认 5 路全参与、≥3 标准）；
4. 可选：按「进入预警根数」筛选——只要「刚进入 1~3 天」的新鲜预警，或只要「15 天以上」的长期预警；
5. 点击「开始扫描」，进度条实时显示（事件 `massZoneScanProgress` 300ms 节流推送，命中逐条经 `massZoneScanHit` 推送）；
6. 扫描可中途停止；面板销毁不影响扫描继续（Go 侧单例管理生命周期，重新打开页签自动接上进度）。

### 1.3 结果展示与导出

- 结果按「**趋势分降序 → MI 超出进入线幅度降序**」排列，一眼看到趋势最强、凸起最猛的标的；
- 每行展示：最新价 / 涨跌%、MI 值与进入线（自适应或经典阈值）、进入预警根数与预警起始日期、趋势分（满足/参与）与各路证据明细、MA20 / MA60；
- 点击行内标的可打开 **K 线弹窗** 复核预警竖带；
- 「导出 Excel」弹系统保存框，导出全部命中字段（用户取消不报错）。

## 二、MASS 反转策略回测（入口已隐藏）

对 MASS 反转策略做全市场历史回测：固定「凸起首日收盘买入」（对应实盘尾盘确认口径，同一凸起只入场一次），9 种卖出策略对每次入场**并行模拟**，并按入场日的 5 路趋势证据分（0~5）**分桶统计**，直接验证「趋势过滤是否带来增益」。

> ⚠️ **入口已隐藏**：本期该功能仅保留代码，页签默认不显示。需要时打开 `frontend/src/components/SignalMonitorPanel.vue`，取消第 694 行注释即可恢复：
> `<NTabPane name="massBacktest" tab="MASS策略回测" />`

### 2.1 回测口径

- **入场**：日K 收盘后确认「MI 首次越过自适应进入线」（凸起首日），以信号日收盘价买入；
- **无未来函数**：阈值 point-in-time，只用截至信号日的 MI 历史样本算 P90；
- **9 种卖出策略并行**：

| 策略 | 规则 |
|------|------|
| 持有3日 / 5日 / 10日 / 20日 | 固定持有期后卖出 |
| MI离开线 | MI 跌破离开线（进入线 − 0.5）卖出 |
| 破MA10 / 破MA20 | 收盘自上向下穿越对应均线卖出 |
| 盈10/损8 | 止盈 +10% 或止损 −8%，先到先卖 |
| 组合 | MI 跌破离开线 **或** 破 MA20，先到先卖 |

### 2.2 分桶统计

逐笔入场按「入场日 5 路趋势证据分」分桶：**全部 / 趋势≥3 / 趋势≥4 / 趋势=5 / 趋势≤2**。输出「卖出策略 × 分桶」统计矩阵（胜率、平均收益、盈亏比等），用于回答：只做趋势分高的入场，哪种卖法更优。

### 2.3 参数与输出

| 参数 | 可选值 | 默认 |
|------|--------|------|
| 市场范围 / 板块细分 | 同 MASS 预警扫描 | 全部 |
| 日K回看根数 | 300（约1.2年）/ 500（约2年）/ 800（约3.2年） | 500 |
| 抽样只数 | 500 / 1000 / 2000 / 全部 | 500 |

全市场数千只全量回测需数分钟到十几分钟，进度与逐笔入场事件流式推送（保留最近 1000 条明细），最终统计支持 Excel 导出。

## 三、全市场信号扫描板块细分过滤

「全市场信号扫描」页签同步获得两项增强：

1. **板块细分多选**：新增「主板 / 创业板 / 科创板 / 北交所」多选过滤（不选 = 全部），与 MASS 扫描同一套板块口径；
2. **剔除非个股**：扫描自动剔除 ETF、债券等非股票标的（`isAShareStock` 校验），命中结果不再混入基金/债券。

## 四、边缘触发条拖拽吸附

AI 助手与信号监控的边缘触发条（贴边的竖条按钮）支持自由拖拽：

- **长按拖动**：按住触发条可任意拖动位置；
- **脱离边缘变圆球**：拖离左/右边缘时，竖条变为 48px 圆形小图标，不遮挡内容；
- **靠近边缘自动吸附**：拖到距左/右边缘 ≤ 28px 时自动吸附，恢复竖条形态；
- **位置记忆**：位置经 localStorage 持久化，重启应用后保持。

两个触发条（AI 助手、信号监控）各自独立记忆位置。
