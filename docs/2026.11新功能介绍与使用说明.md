## 一、MASS 反转预警扫描（多周期）

全市场扫描「当前正处于 Mass Index（MI）反转预警窗口——凸起已形成、尚未回落确认」且「处于多头/上升趋势」的标的。MASS 口径与 K 线主图的琥珀色预警竖带完全一致：自适应进入线 = 自身 MI 历史 P90（钳制在 24~31），离开线 = 进入线 − 0.5；趋势口径复刻趋势扫描的 5 路证据等权计分。

### 1.1 入口与参数

入口：信号监控面板 → 「**MASS预警扫描**」页签。

| 参数 | 可选值 | 默认 | 说明 |
|------|--------|------|------|
| 市场范围 | 沪市 / 深市 / 北交所（多选） | 不选 = 全部 | 缩小扫描范围 |
| 板块细分 | 主板 / 创业板 / 科创板 / 北交所（多选） | 不选 = 全部 | 精确到板块过滤 |
| K线周期 | 日K / 60分 / 30分 / 15分 / 5分 / 1分 / 周K | 日K | 同一指标在不同周期下独立扫描预警窗口 |
| 趋势指标自选 | 多头排列 / MA20上行 / Supertrend翻多 / ADX强多头 / 通道上半区（多选） | 不选 = 全部 5 路参与计分 | 只勾选关注的证据，其余不参与计分 |
| 趋势过滤 | 满足 ≥1（宽松）/ ≥2 / ≥3（标准）/ ≥4 / 全部满足 | ≥3 | 在自选指标范围内按满足个数过滤（后端自动钳制到自选个数） |
| 进入预警根数 | 不限 / 刚进入 1~3 / 4~7 / 8~15（持续预警）/ 15 以上（长期预警） | 不限 | 从 MI 越过进入线那根起算。计数单位跟随周期：日K = 天、周K = 周、分钟 = 根 |

### 1.2 使用步骤

1. 打开信号监控面板，切到「MASS预警扫描」页签；
2. 按需设置市场范围、板块细分、K线周期；
3. 自选趋势指标并选择过滤档位（不选指标 = 默认 5 路全参与、≥3 标准）；
4. 可选：按「进入预警根数」筛选——只要「刚进入 1~3 天」的新鲜预警，或只要「15 天以上」的长期预警；
5. 点击「开始扫描」，进度条实时显示（事件 `massZoneScanProgress` 300ms 节流推送，命中逐条经 `massZoneScanHit` 推送）；
6. 扫描可中途停止；面板销毁不影响扫描继续（Go 侧单例管理生命周期，重新打开页签自动接上进度）。

### 1.3 结果展示与导出

- 结果按「**趋势分降序 → MI 超出进入线幅度降序**」排列，一眼看到趋势最强、凸起最猛的标的；
- 每行展示：最新价 / 涨跌%、MI 值与进入线（自适应或经典阈值）、进入预警根数与预警起始日期、趋势分（满足/参与）与各路证据明细、MA20 / MA60；
- 点击行内标的可打开 **K 线弹窗** 复核预警竖带；
- 「导出 Excel」弹系统保存框，导出全部命中字段（用户取消不报错）。

## 二、MASS 反转策略回测（入口已隐藏）

对 MASS 反转策略做全市场历史回测：固定「凸起首日收盘买入」（对应实盘尾盘确认口径，同一凸起只入场一次），9 种卖出策略对每次入场**并行模拟**，并按入场日的 5 路趋势证据分（0~5）**分桶统计**，直接验证「趋势过滤是否带来增益」。

> ⚠️ **入口已隐藏**：本期该功能仅保留代码，页签默认不显示。需要时打开 `frontend/src/components/SignalMonitorPanel.vue`，取消第 694 行注释即可恢复：
> `<NTabPane name="massBacktest" tab="MASS策略回测" />`

### 2.1 回测口径

- **入场**：日K 收盘后确认「MI 首次越过自适应进入线」（凸起首日），以信号日收盘价买入；
- **无未来函数**：阈值 point-in-time，只用截至信号日的 MI 历史样本算 P90；
- **9 种卖出策略并行**：

| 策略 | 规则 |
|------|------|
| 持有3日 / 5日 / 10日 / 20日 | 固定持有期后卖出 |
| MI离开线 | MI 跌破离开线（进入线 − 0.5）卖出 |
| 破MA10 / 破MA20 | 收盘自上向下穿越对应均线卖出 |
| 盈10/损8 | 止盈 +10% 或止损 −8%，先到先卖 |
| 组合 | MI 跌破离开线 **或** 破 MA20，先到先卖 |

### 2.2 分桶统计

逐笔入场按「入场日 5 路趋势证据分」分桶：**全部 / 趋势≥3 / 趋势≥4 / 趋势=5 / 趋势≤2**。输出「卖出策略 × 分桶」统计矩阵（胜率、平均收益、盈亏比等），用于回答：只做趋势分高的入场，哪种卖法更优。

### 2.3 参数与输出

| 参数 | 可选值 | 默认 |
|------|--------|------|
| 市场范围 / 板块细分 | 同 MASS 预警扫描 | 全部 |
| 日K回看根数 | 300（约1.2年）/ 500（约2年）/ 800（约3.2年） | 500 |
| 抽样只数 | 500 / 1000 / 2000 / 全部 | 500 |

全市场数千只全量回测需数分钟到十几分钟，进度与逐笔入场事件流式推送（保留最近 1000 条明细），最终统计支持 Excel 导出。

## 四、边缘触发条拖拽吸附

AI 助手与信号监控的边缘触发条（贴边的竖条按钮）支持自由拖拽：

- **长按拖动**：按住触发条可任意拖动位置；
- **脱离边缘变圆球**：拖离左/右边缘时，竖条变为 48px 圆形小图标，不遮挡内容；
- **靠近边缘自动吸附**：拖到距左/右边缘 ≤ 28px 时自动吸附，恢复竖条形态；
- **位置记忆**：位置经 localStorage 持久化，重启应用后保持。

两个触发条（AI 助手、信号监控）各自独立记忆位置。

买卖点预测从固定权重打分重构为 **路由注册表 + 组合模式** 体系，全部等权计分、分组门控，口径与 K 线图箭头完全一致。

|----|------|------|------|

| 量价组 | VWAP | 收复 | 跌破 |
| 量价组 | 成交量 | 放量 | 放量 |
| 量价组 | MFI(14) | 上穿 20 | 下穿 80 |

| 摆动区组 | SMI 区域 | 底部区转强 | 顶部区转弱 |

### 5.2 指标组合模式（score / any / all）

在信号监控面板「检测参数」中可自选一个或多个指标路由作为操盘点，并选择触发模式：

| 模式 | 触发条件 | 适用场景 |
|------|----------|----------|
| `score`（默认） | 共振分数达标（滚动窗口内命中路数 + 覆盖组数满足灵敏度档位） | 沿用原有共振语义 |
| `any` | 选中的路由中**任一路命中**即出信号 | 只想做单一信号（如只做 MACD 金叉） |
| `all` | 滚动窗口内**全部选中路由齐备**才出信号 | 多条件同时满足的严格入场 |

- 股票监控 / OKX 模拟盘 / OKX 实盘**三实例独立配置**路由与组合模式；
- 组合配置纳入基线指纹，修改配置不会吞掉已经武装、尚未触发的信号；
- 信号流水记录触发模式（`ScoreMode`），`any` / `all` 模式下强度字段记录窗口内命中路由数。

### 5.3 与全市场扫描/自动交易的关系

Go 侧（全市场扫描、后台监控、OKX 自动交易）与前端 `calc.ts` 逐行同口径复刻：

- 基础 15 路满分，等权计数；
- 日K类周期启用 **4 路扩展维度**（BIAS 乖离率、K 线形态、获利盘比例、多周期共振）时满分 **15→19**，命中门限按 19/15 等比放大（灵敏/标准/严格 ≈ 4/6/7 → 5/8/9），保持档位语义；
- RS 相对强度因全市场逐只拉基准指数成本过高，暂不接入打分。

## 七、K 线新增四种反转信号指标（2026.11.15）

K 线主图新增 4 种反转信号标注，均为「预警(预) → 确认(确) → 失效(失)」三态、纯因果无未来函数：

| 信号 | 预警条件 | 确认条件 |
|------|----------|----------|
| 假突破反转 | 跌破前 20 根低点或突破前 20 根高点 | 10 根内收盘收回；收盘突破预警K线极值或超时失效 |
| RSI 摆动 | RSI 在超卖/超买区摆动反转 | 详见指标提示（悬停指标名可见完整口径） |
| 衰竭量反转 | 下跌后放量（> 前20根均量 × 1.8）出现长下影或看涨吞没 | 10 根内收盘突破预警K线最高价；跌破其最低价或超时失效 |
| 双底/双顶 | 两个拐点间隔 4~40 根、价差 ≤3% | 10 根内收盘突破颈线；跌破双底（双顶反向）或超时失效 |

- 红色看涨、绿色看跌、灰色失效；「预」为预警、「确」为确认、「失」为失效；
- 悬停左侧指标栏对应指标名可查看完整口径说明。

## 九、信号流水筛选跨天常驻与默认区间滚动（2026.11.17）

信号监控面板常驻后台、可能跨天不关闭，筛选体验针对性优化：

- **默认只看今天**：筛选区间默认预填东八区「今天」整天，打开面板即聚焦当天信号；
- **跨天自动滚动**：面板跨天后再打开，若用户未手动修改过筛选，默认区间自动滚动到当前自然日并重新查询；
- **重置筛选**：一键恢复默认（关键词清空、区间回到今天、方向不限）；
- **新信号实时并入**：默认区间视同无筛选，当天新信号仍可实时并入第一页；
- 修复切换页签 / 重置后输入控件与实例筛选状态不同步的问题。

## 十、通达信异动监控与新增数据源（2026.11.15 - 2026.11.16）

### 10.1 通达信异动监控

- 入口：设置 → 通知设置 → 「通达信异动通知」；
- 开启后，沪深 A 股交易时段每 30 秒读取通达信主站异动，在软件内合并提醒（每次最多显示 8 条与异动总数）；
- 不发送系统/飞书/钉钉通知；首次开启与每个交易日首次读取仅建立基线，不补发历史事件；
- 不覆盖北交所；通达信与东方财富的异动定义可能不同。

### 10.2 Yahoo Finance 数据源

- 港美股不复权日 K 线备用源：通达信 MAC 与东方财富均失败时自动回退（仅不复权日线，前/后复权不使用该源）；
- AI 智能体新增个股新闻搜索工具（如「搜索 AAPL.US 的 Yahoo 财经新闻」）；
- 非官方接口、无需 API Key，走设置中的海外代理；不可用于历史时点回测。

### 10.3 Bloomberg 市场新闻数据源

- 市场行情新增 Bloomberg Markets RSS 新闻（标题/摘要/原文链接）；
- 接入 Agent 工具，AI 可直接检索彭博市场新闻。
