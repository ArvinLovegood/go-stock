# 后台买卖点信号监控 · 功能介绍与使用说明

> 一句话：把 K 线图上那套买卖点（9 路共振）与 TEMA 转折（T确）判断搬到后台常驻运行，命中就主动提醒你，并把历史信号、按信号操作的收益与胜率一并记录下来。

**权限**：需 **VIP2 及以上**赞助用户。权限不足时点击侧边「信号监控」浮标会提示升级，面板不会打开，后台也不会启动扫描。

---

## 1. 它解决什么问题

在 K 线图上盯买卖点，必须满足三个前提：图表开着、那只票在当前视野、你正好在看。盘中同时盯十几只票、还要切周期，几乎做不到。

信号监控把这套判断做成**后台任务**：

- 你只管维护一份「监控池」，剩下的交给后台；
- 窗口最小化、切到别的菜单，扫描照常进行（节拍在 Go 侧，不受浏览器定时器节流影响）；
- 命中信号会通过系统通知 / 飞书 / 钉钉推给你，应用内还能响提示音；
- 所有信号自动入库，事后能按股票、按时间区间回看，并统计「如果照信号操作」的收益和胜率。

关键前提：**算法与取数口径和 K 线图完全一致**——同一套买卖点算法、同样的复权与 K 线根数。所以面板里出现的信号，在图上一定能找到对应箭头；反过来，图上有箭头、面板没提醒，通常只是那根 K 线在你开启监控之前就已经形成（历史箭头不补播）。

## 3. 快速上手

1. 点击侧边的「信号监控」浮标，打开右侧抽屉面板（浮标上的红色角标是未读信号数）。
2. 在「后台监控」一栏打开总开关 —— **必须在交易时段**才会有扫描动作。
3. 添加监控池：从「从自选股选择」下拉里挑，或直接输入代码（如 `600519`、`sz002245`）后点「添加」。
4. 按需微调「检测参数」：默认周期、买卖点灵敏度、启用哪些信号族。
5. 勾选「提醒渠道」，建议至少保留「系统通知」；想第一时间知道就打开「提示音」。
6. 之后就不用管了。新信号会推给你，并在「信号流水」里留档；「信号收益统计」会同步更新。

> 面板里的设置（开关、监控池、周期、灵敏度、渠道、提示音）会自动保存，重启软件后依然生效。

## 4. 功能详解

### 4.1 监控池

- **上限 50 只**，与「股票自选」完全解耦：自选股删了不影响监控，监控池加票也不需要先加自选。
- 添加方式：从自选股下拉里选择，或手输代码（支持 `600519`、`sh600519`、`002245.SZ` 等写法，会自动归一化）。
- 每行是一只票，右边是**该票的监控周期**多选框：
  - 勾一个或多个周期（如同时勾 日K 与 60分），会**各自独立出信号**，互不干扰；
  - 留空 = 继承「检测参数」里的**默认周期**（推荐用法：共性周期设为默认，个别票再单独覆盖）。
- 改周期后，该票在旧周期上已经存在的历史信号不会被当作新信号补播。
- 点「×」把票移出监控池；点股票名称可以直接打开该票的 K 线图核对。

### 4.2 检测参数

| 参数 | 说明 |
|------|------|
| 默认周期 | 所有未单独设置周期的票都按它扫描；可选 1分 / 5分 / 15分 / 30分 / 60分 / 日K / 周K |
| 灵敏度 | **灵敏**（共振路数要求最低，信号最多）/ **标准**（默认）/ **严格**（要求最高，信号最少） |
| 信号族 | 「买卖点（9 路共振）」为买卖点信号；「TEMA 转折（T确）」为趋势转折提示 |

> 为什么不提供月K / 季K / 年K：买卖点门控依赖 MA250 与近 250 根 K 线的波动基准，月K（240 根）、季K、年K 的 K 线根数不足会让门控静默失效，出现「面板有信号但图上没箭头」的错位，因此直接从可选周期里排除。

### 4.3 提醒

- **渠道**：系统通知（同时弹应用内横幅）、飞书、钉钉，可多选。
- **合并推送**：同一轮扫描命中的多只票会合并成一条消息，不会刷屏；应用内提示音则按信号依次连播。
- **提示音**：可在面板右上角开关。提示音与 K 线图共用同一套「抢占式去重」——同一根 K 线同一类型信号，图表和后台谁先提醒谁占用，不会重复响。
- **语音报名称**：打开后，每段短音放完会再用系统语音念一句「股票名称 + 方向」（如「贵州茅台 买点」），多只票同时命中时不用回到屏幕也能分辨是哪一只。依赖系统中文语音包（Windows 在「时间和语言 → 语言」中添加中文语音）；开启后连播间隔会放宽，播报节奏更慢。关闭提示音时语音不单独启用。
- **不重复提醒**：同一根 K 线、同一类型、同一周期，只提醒一次；K 线时间推进后才会产生新的提醒。

### 4.4 扫描节拍

- 由 Go 侧每 60 秒派发一次扫描节拍，**窗口最小化也会持续提醒**；关闭窗口即退出应用，监控随之停止。
- 只在**交易时段**扫描：A 股、港股、美股各自按其交易时间判断，非交易时段不做任何取数。
- 池子较大时（一只票 × 一个周期算一个任务）一轮扫不完，会按轮转顺序分多轮覆盖，保证长池里的每只票都能轮到，而不是永远只扫前几只。
- 想立刻看结果，点右上角「立即扫描」。

### 4.5 信号流水

每次命中的信号都会落到后端 SQLite，重启软件不丢。

| 字段 | 含义 |
|------|------|
| 类型 | 买点 / 卖点 / T确买 / T确卖 |
| 名称 + 代码 | 信号所属股票 |
| 周期 | 该信号来自哪个周期（同一票多周期时用于区分） |
| 时间 | **信号所在 K 线的时间**（如 1分周期即那一分钟、日K 即当日） |
| 价格 / 强度 | 信号价与共振强度（买卖点带强度，TEMA 转折不带强度） |

- **筛选**：代码/名称关键词 + K 线时间区间（日期时间控件，清空需确认），两项在同一行，点「查询」生效，「重置」清空。
- **分页**：默认 20 条/页，可切 50 / 100 条，最新在前。
- **一键看 K 线**：每条流水右侧的图标按钮直接打开该票 K 线弹窗，方便立刻核对信号形态。
- **清空**：二次确认后清空全部流水（不限于当前筛选结果，且不可恢复）。
- 浮标角标显示的是「自上次打开面板以来新到的信号数」，打开面板即清零。

### 4.6 信号收益统计

把买卖点信号当作交易信号来回测：**买点开仓、卖点平仓**，逐笔配对算收益。

- **统计口径**
  - 只统计买卖点信号，TEMA 转折不参与配对；
  - 每笔按信号价计算 `(卖价 − 买价) / 买价`，累计收益为各笔收益率之和；
  - 同一根周期内逐笔配对；同一只票配了多个周期时，各周期各自成笔，最后按股票汇总展示；
  - 只有买点、还没等到卖点的记为「**持仓中**」，不计入胜率；
  - 区间起点之前买入、区间内才卖出的卖点找不到对应买点，不成笔。
- **区间**：今日 / 3日 / 5日 / 10日 / 20日（按东八区自然日，含今天）快捷切换，或自定义日期区间；统计按**信号的 K 线时间**落区间。
- **指标**：累计收益（涨红跌绿）、胜率（含 `盈利笔数/总笔数`）、笔数、持仓中。
- **按股票明细**：每只票一行（笔数 / 胜率 / 收益率 / 持仓），按收益率从高到低排序，点名称可直接看 K 线。

> 收益是「信号回测值」，不是实盘成交结果：按信号价满仓计算，未计手续费、滑点、涨跌停无法成交等情况。

## 5. 使用建议

1. **先小池验证**：初期放 3～5 只熟悉的票，跑一两天，把面板信号与图上箭头对一遍，确认灵敏度档位适合自己。
2. **默认周期定基调**：想做日线级别波段就把默认周期设成日K；只有个别票需要看 60 分或 1 分，再单独给它们勾周期。
3. **灵敏度按风格选**：信号太少选「灵敏」，噪声太多选「严格」；换档后旧基线会重建，不会补播历史信号。
4. **渠道分层**：系统通知常开（本地、无依赖），飞书/钉钉适合无人值守时远程接收。
5. **盘后用流水复盘**：按 K 线时间筛选当天区间，看哪些票反复出信号，配合「收益统计」判断哪只票的信号更值得跟。
6. **不要只看胜率**：胜率高但累计收益低，说明赚小亏大；两个指标一起看，再结合持仓中的笔数判断是否还在等待卖点。

## 6. 常见问题

**Q：为什么开了监控没收到任何提醒？**
先确认三点：总开关已打开、监控池里有票（且已添加成功）、当前处于交易时段。非交易时段不会扫描，点「立即扫描」也会提示「本轮未发现新信号」。

**Q：为什么图上有箭头，面板没提醒？**
两种可能：一是那根 K 线在你开启监控/添加该票之前就已形成，历史信号一律不补播（避免一开就响一片）；二是该票当前监控的周期与图上周期不一致——多周期监控时各周期独立判断。

**Q：面板信号和图上箭头对不上？**
极少见。取数与图表保持一致（同样的复权、同样的 K 线根数，每只票至少 300 根），若真出现，多半是该票在所选大周期上 K 线根数不足，换小周期或换票再试。

**Q：删掉自选股会影响监控吗？**
不会。监控池与自选股互相独立。

**Q：重启软件后流水和统计会丢吗？**
不会。信号流水与收益统计都存在本地 SQLite 里。

**Q：为什么「持仓中」有数字却没有收益？**
说明该票只有买点、还没等到卖点，自然没有配对收益；等卖点出现后会自动成笔并计入胜率。
