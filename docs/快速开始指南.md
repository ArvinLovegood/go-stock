# go-stock 快速开始指南

> 面向新用户的 4 步上手指南，10 分钟从安装到完成第一次 AI 分析。
> 完整功能说明请参阅 [go-stock 使用手册](./go-stock使用手册.md)。

---

## 整体流程

```
① 设置：基础设置 + AI 模型  →  ② 研究中心：参考提示词  →  ③ AI 助手：选模型/提示词  →  ④ 发送分析请求
```

---

## 第一步：配置基础设置与 AI 模型

打开应用后，进入左侧菜单 **设置** 页面。

### 1.1 基础设置

在「基础设置」卡片中，按需调整以下选项（均可保持默认）：

| 选项 | 说明 | 建议 |
| --- | --- | --- |
| 启动时更新基础信息 | 启动时自动刷新股票基础数据 | 首次使用建议开启 |
| 数据刷新间隔 | 行情数据刷新频率（秒） | 默认 1 秒 |
| 暗黑主题 | 切换深色/浅色界面 | 个人喜好 |
| 更新通道 | Release / Pre-release / Dev | 新用户选 Release（稳定版） |
| 浏览器安装路径 | 抓取资讯所用浏览器 | 留空则使用 Edge |
| 指数基金 | 显示基金模块 | 按需开启 |

### 1.2 配置 AI 模型（关键步骤）

1. 在设置页找到 **AI 分析配置** 区块，打开「启用」开关。
2. 区块下方会出现「**AI 模型服务配置**」提示框，点击 **前往管理** 按钮，跳转到独立的 AI 模型配置页面。
3. 在配置页面新增一条 AI 模型配置，填写：
   - **名称**：便于识别（如「DeepSeek-Chat」）
   - **模型平台 / 接口地址**：填供应商的 OpenAI 兼容地址
   - **API Key**：对应平台的密钥
   - **模型名称**：如 `deepseek-chat`、`gpt-4o-mini` 等
4. 保存配置后返回设置页，点击底部 **保存设置**。

> 支持平台：DeepSeek、硅基流动、智谱 AI、字节豆包、阿里云百炼、Moonshot、腾讯混元、讯飞星火、OpenAI、Azure OpenAI、OpenRouter、Ollama 等所有兼容 OpenAI API 格式的平台。

## 第二步：研究中心参考提示词

进入左侧菜单 **研究中心**，切换到以下页签获取/管理提示词：

- **提示词模板**：本地提示词管理，可新建/编辑/删除，分「模型系统 Prompt」和「用户 Prompt」两类。
- **提示词广场**：社区共享的系统/用户提示词，可一键应用到本地。
- **问答广场**：参考其他用户的提问与回答样例，学习如何提问。

建议至少保存一条「模型系统 Prompt」（定义 AI 角色与分析风格）和一条「用户 Prompt」（如选股/分析模板），后续在 AI 助手中可直接选用。

> 也可以直接使用「**AI 分析报告**」页签查看历史 AI 分析结果作为参考。

---

## 第三步：打开 AI 助手并选择模型与提示词

### 3.1 唤起 AI 助手

在任意页面右侧边缘找到 **聊天图标触发条**，单击或悬停即可从右侧滑出「go-stock AI 助手」抽屉面板。

> 触发条若呈现高亮状态，表示助手正在后台执行分析任务。

### 3.2 底部输入区选择配置

抽屉底部输入框上方依次排列以下控件：

| 控件 | 作用 |
| --- | --- |
| **选择模型** | 下拉选择第一步配置的 AI 模型（支持搜索过滤） |
| **系统提示词** | 选择第二步准备的「模型系统 Prompt」（可清空） |
| **用户提示词** | 选择「用户 Prompt」模板，选中后内容自动填入输入框 |
| **思考模式** | 开启后模型进行推理思考（需模型支持） |
| **记忆模式** | 开启后保留上下文多轮对话，可设置记忆条数 |

依次设置好模型与提示词后，即可进入下一步。

---

## 第四步：发送选股或分析请求

在底部输入框输入需求，**回车** 或点击 **发送** 按钮即可开始 AI 分析。

### 4.1 常用提问示例

**选股类：**
```
帮我筛选 A 股中市值小于 200 亿、近 5 日主力净流入为正、PE 小于 30 的股票
```

```
推荐半导体板块中近期放量上涨且 MACD 金叉的个股
```

**个股分析类：**
```
分析贵州茅台（600519）近期的资金流向、技术形态和基本面
```

```
对比宁德时代和比亚迪的财务数据与机构研报观点
```

**市场综合类：**
```
总结今日 A 股市场热点板块、龙虎榜异动与重大资讯
```

### 4.2 对话操作

- **新对话**：点击面板顶部「新对话」按钮清空上下文。
- **中断**：分析过程中可点击「中断」按钮停止生成。
- **复制 / 导出图 / 分享**：每条 AI 回复下方可一键复制、导出为图片或分享到社区。
- **多轮追问**：在记忆模式开启时，可基于上一轮结果继续提问（如「上面第一只股票的 K 线形态如何？」）。

## 常见问题

| 问题 | 解决方法 |
| --- | --- |
| 模型下拉为空 | 回到设置页确认已新增 AI 模型配置并保存 |
| 发送后无响应/报错 | 检查 API Key、接口地址是否正确；套餐接口需使用专属 Key（通常 `sk-sp-` 开头） |
| 提示词下拉为空 | 在「研究中心 → 提示词模板」中先新增对应类型的提示词 |
| 分析结果不理想 | 尝试切换更强模型、优化系统提示词、开启思考模式 |
| 港美股分析无数据 | 确认股票代码格式正确（如 `00700.HK`、`AAPL.US`） |
