## 一、每日复盘

AI 在收盘后自动生成当日复盘报告，把「看盘—交易—复盘」闭环交给 AI。

### 1.1 手动生成

1. 进入「复盘策略 → 每日复盘」；
2. 选择日期、AI 配置、提示词模板（默认内置复盘提示词）与分析模式；
3. 点击生成，页面轮询刷新生成状态，完成后展示 Markdown 报告。

### 1.2 报告内容

| 板块 | 说明 |
|------|------|
| 市场概况与情绪定位 | 当日指数行情、涨跌家数、市场统计快照 |
| 主线与板块 | 当日强势主线、板块资金流异动 |
| 我的交易复盘 | 自动读取当日交易记录，结合买卖点位复盘 |
| 龙虎榜与资金 | 当日龙虎榜游资/机构动向 |
| 明日展望 | 结合昨日盘前策略预判给出次日思路 |

### 1.3 定时自动生成

- 应用启动时自动创建 `daily_review` 定时任务（**默认启用**，交易日 **18:00** 执行）；
- 在「任务管理」页面选择每日复盘任务，可配置：AI 配置、提示词、分析模式、是否包含龙虎榜、**飞书/钉钉推送**（默认关闭）；
- 生成完成后自动推送事件刷新前端，也可在任务管理页「立即执行」手动触发。

## 二、盘前策略

AI 在开盘前生成当日盘前必读，与每日复盘共用同一套操作逻辑。

### 2.1 功能说明

- **入口**：「复盘策略 → 盘前策略」，选择日期、AI 配置、模板后生成；
- **内容**：聚合隔夜市场信息、自选股动态与预警提醒，输出开盘前操作参考；
- **闭环**：盘前策略生成结果会被**次日复盘报告自动引用**，形成「盘前预判 → 盘后验证」闭环。

### 2.2 定时任务

- 应用启动时自动创建 `morning_strategy` 定时任务（默认启用），在「任务管理」页面可调整执行时间与推送配置，方式与每日复盘一致。

## 三、提示词模板回测（beta）

用历史行情**重放**的方式，量化对比多个提示词模板的选股质量。试验阶段功能，指标口径持续迭代。

### 3.1 创建回测任务

进入「复盘策略 → 提示词回测(beta)」，填写表单：

| 字段 | 说明 |
|------|------|
| 提示词模板 | 最多选择 **5 个**模板同时对比 |
| AI 配置 | 使用的模型配置（注意调用配额） |
| 回测日期区间 | 历史交易日区间 |
| 持有周期 | 选股后持有 N 个交易日计算收益 |
| 选股上限 | 每日每模板最多选股数量 |
| 重复次数 | 同一交易日重复调用次数（用于计算输出稳定性，>1 才有 Jaccard） |
| 采样密度 | 区间内按密度抽取交易日，控制调用成本 |

> ⚠️ **成本提示**：调用次数 = 模板数 × 采样交易日数 × 重复次数，请留意 AI 配额消耗。

### 3.2 防未来数据机制

每个历史交易日只使用**当日及之前**的数据素材（指数行情、市场统计、涨停梯队、龙虎榜游资动向、板块资金流等）构建提示输入，选股后以**后 N 交易日的实际行情**计算收益，杜绝未来函数，保证回测可信。

### 3.3 结果解读

任务详情页展示各模板对比表与等权组合净值曲线：

| 指标 | 含义 |
|------|------|
| 胜率 / 超额胜率 | 收益为正的比例 / 跑赢基准的比例 |
| 平均收益 / 平均超额 | 持有期平均收益 / 相对基准的平均超额 |
| 波动率 / CV | 收益波动 / 变异系数（越低越稳定） |
| 夏普比率 | 风险调整后收益 |
| 最大回撤 | 净值曲线最大回撤 |
| Jaccard 输出稳定性 | 同日多次调用的选股集合重合度（0~1，越高输出越稳定；重复次数 = 1 时显示"—"） |

点击对比表中的模板行，可查看该模板**逐日选股明细**。回测任务异步执行，列表页可实时查看进度（`已完成调用数/总调用数`）。

## 四、推荐回测统计

对 AI 已经推荐过的个股做**事后验证**：按 5 个交易日持有期计算实际收益，与沪深300 对比。

### 4.1 使用步骤

1. 进入「复盘策略 → 推荐回测统计」；
2. 点击「**执行回测(5日)**」：对历史推荐记录批量计算持有期收益（数据量大时需等待）；
3. 点击「**刷新统计**」重新汇总最新统计结果。

### 4.2 统计维度

| 维度 | 内容 |
|------|------|
| 总体统计 | 已回测数、达标数（跑赢基准）、未达标数、胜率 |
| 按评级胜率 | 推荐 rating（1~5 星）与实际收益的关系 |
| 按提示词统计 | 不同系统/用户提示词的推荐质量 |
| 按模板统计 | 按提示词模板（SysPromptId）分组统计 |
| 最佳模型 | 按 AI 模型配置聚合的排行榜 |

点击提示词/模板行可**过滤下方明细**，定位高质量推荐的来源。

> 💡 数据基础：AI 分析时推荐的股票会**自动保存**推荐记录（无需手动操作），推荐记录关联模型与提示词上下文。

## 五、AI 视觉理解（图片对话）

截图问股、K 线图分析，让 AI「看得见」。

### 5.1 开启方式

1. 进入「设置 → AI 模型服务」，编辑某条 AI 配置；
2. 打开「**视觉理解**」开关（需该配置绑定多模态模型，如 GLM-4V、Qwen-VL、GPT-4o 等）；
3. 配置列表会出现「视觉理解」能力标记。

### 5.2 使用方式

在 AI 智能体或浮动 AI 助手对话中，点击输入框「图片」按钮添加图片：

- **上传本地图片**：选择文件；
- **粘贴截图**：直接 Ctrl+V 粘贴；
- **图片链接**：输入图片 URL。

### 5.3 多模型自动适配

| 模型系 | 适配方式 |
|--------|----------|
| OpenAI 系（含 DeepSeek-Vision） | 图片 URL 直传 |
| Claude | base64 自动拆解 |
| Gemini / Ollama | 后端下载外链转 base64 |

本地图片默认经图床转外链发送，失败自动回退 base64 直传。详细说明见《[AI对话与视觉理解功能说明](./AI对话与视觉理解功能说明.md)》。

## 六、Agent 自我进化层

AI 在每次任务后**自动内省沉淀经验**，越用越懂你。

### 6.1 工作机制

```
SOUL.md（进化规则） + MEMORY.md（长期记忆） + .learnings/LEARNINGS.md（经验沉淀）
        ↓ 每次 AI 会话自动注入系统提示词
   AI 按进化规则执行任务 → 任务后自动内省 → 经验追加到 LEARNINGS.md
```

- **开箱即用**：首次运行自动落盘内置 SOUL.md 进化规则种子（P0-P6 规则体系）；
- **自动注入**：每次 AI 会话自动将进化规则、长期记忆与最近经验注入上下文（与知识库长期记忆语义召回联动）；
- **持续积累**：任务结束后自动复盘得失，经验写入 `.learnings/LEARNINGS.md`，供后续任务引用。

### 6.2 自定义与禁用

文件位于**程序所在目录**（`GO_STOCK_ROOT_DIR` 环境变量指定时以其为准）：

| 文件 | 作用 | 自定义 |
|------|------|--------|
| `SOUL.md` | 进化规则（P0-P6） | 可直接编辑为自定义规则；**清空文件即禁用**（不会重新写入） |
| `MEMORY.md` | 长期记忆 | 可手动维护 |
| `.learnings/LEARNINGS.md` | 经验沉淀 | 可编辑/清理历史经验 |

## 七、市场行情新数据

### 7.1 游资动向

「市场行情 → 游资动向」标签页，汇总当日龙虎榜**全部上榜个股**的席位明细：

- **游资聚合**：按知名游资聚合展示当日上榜个股、买卖金额与净额，标注风格与风险等级；
- **机构聚合**：机构席位的买卖行为汇总；
- **识别能力**：内置知名游资营业部席位映射表（2026.08 版，已适配国泰海通席位更名）；
- 首次查询需汇总全量席位明细（约几秒），结果缓存 10 分钟。

### 7.2 游资名录维护

在「市场行情 → 龙虎榜」页面点击「**游资名录**」按钮，打开维护抽屉：

| 配置项 | 说明 |
|--------|------|
| 游资席位 | 一行一条：`营业部名称`，保存后即时生效 |
| 游资真名/梯队/风险 | 对游资席位补充标注（用于游资动向页展示） |
| 散户集中营席位 | 每行一个席位名称 |
| 量化/机构通道席位 | 格式：`席位名称\|类型` |
| 远程同步（可选） | 从远程拉取最新游资名录 |

### 7.3 部委政策新闻

「市场行情 → 政策新闻」标签页：

- 聚合各部委政策新闻，展示日期、来源部门、标题与原文链接；
- 支持按**部门筛选**与**关键词搜索**；
- 政策新闻已接入 AI 智能体（支持部门关键词过滤与部门检索参数），可直接对话分析政策影响。

## 八、K 线六项技术指标

在个股/指数 K 线图（Lightweight Charts）的指标开关中开启，开关状态**自动持久化**：

| 指标 | 类型 | 说明 |
|------|------|------|
| 成交量分布（VPVR） | 副图 | 仿 TradingView，随可见区间自动重算 POC（成交控制点）/VAH/VAL（价值区间上下沿） |
| 神奇九转（TD Sequential） | 主图标记 | 1-9 数字计数，9 转出现时提示趋势衰竭 |
| 自动背离 | 主图连线 | 价格与指标背离自动检测，支持 **RSI / MACD / KDJ** 三种指标源切换 |
| BBI 多空指标 | 主图叠加线 | BBI = (MA3+MA6+MA12+MA24)/4，收盘价上下穿越给出多空信号 |
| 涨跌停价位线 | 主图横线 | 昨收锚定的当日涨停/跌停价位（自动识别 ST 与北交所档位） |
| 威斯波浪（Weis Wave） | 副图 | 波浪成交量 histogram，量价结构分析 |

> 💡 每个指标开关旁有详细用法提示（含信号解读与组合建议）。

## 十、常见问题

**Q1：提示词回测和推荐回测统计有什么区别？**
A：提示词回测是「主动实验」——在历史区间重放选股，对比模板优劣；推荐回测统计是「事后验证」——对 AI 已真实推荐过的股票核算实际收益。前者选模板，后者验效果。

**Q2：回测会消耗多少 AI 配额？**
A：调用次数 = 模板数 × 采样交易日数 × 重复次数。5 模板 × 20 交易日 × 2 次 = 200 次调用，请先评估配额再开跑。

**Q3：视觉理解开关打开后仍无法发图？**
A：请确认所用模型本身支持多模态；纯文本模型（如部分推理模型）无法解析图片。详见视觉理解功能说明文档的模型支持列表。

**Q4：每日复盘定时任务为什么没执行？**
A：检查任务管理页该任务是否启用、AI 配置是否可用；任务仅交易日执行（默认 18:00），生成失败会在任务状态中记录原因。

**Q5：SOUL.md 在哪里？改了会被覆盖吗？**
A：位于程序所在目录。已存在的 SOUL.md 不会被覆盖，可放心自定义；**清空文件即禁用**自我进化注入。

**Q6：游资动向页为什么首次查询慢？**
A：需汇总当日全量龙虎榜席位明细，结果缓存 10 分钟，稍后查询即秒开。
