## 〇、读前须知：整条链路怎么跑

```
信号监控池（股票/OKX模拟盘池/OKX实盘池，各自独立）
   └─ 买卖点信号命中（14 路指标共振，等权计分）
        └─ 信号按环境派发：模拟盘池 → 「模拟盘自动下单」；实盘池 → 「实盘自动下单」
             └─ 过滤链：周期过滤 → 信号分数 → 开仓方向 → 顺大势 → 冷却 → 单日上限
                  → 开单止盈区间门槛 → 防爆仓风控（持仓数 + 保证金率）
                       └─ 按金额模式换算张数/币数 → 设置杠杆 → 市价下单 → 落流水
                            └─ 持仓期间：止盈止损监控（软件侧 10 秒轮询 + 交易所侧条件单双保险）
```

三个最重要的全局认知：

1. **模拟盘与实盘完全独立**：密钥是两套、每笔金额是两个、风控各自计数、止盈止损各查各的持仓。同一信号若两个池都有，会在两个环境各下一笔、各落一条流水。
2. **所有开关都要「点保存」**：设置页任何修改只在内存态显示，必须点保存按钮并看到「保存成功」提示才落库。拒单提示里的参数数字以库里真值为准。
3. **空值/非法值一律保守回退**：所有数字型输入框留空或填非法值时，后端自动回退到保守默认（详见各参数说明），不会放大风险。

## 一、API 密钥（6 项）

| 参数 | 说明 |
|------|------|
| 模拟盘 API Key / Secret Key / 口令 | 在 OKX「**模拟交易**」环境创建的密钥三件套 |
| 实盘 API Key / Secret Key / 口令 | 在 OKX **正式环境**创建的密钥三件套，动真实资金 |

- 权限勾选「读取」+「交易」；
- **必须把本机出口 IP 加入密钥白名单**，否则私有接口报「IP 不可用」错误；
- 「口令」（Passphrase）是创建密钥时你自己设置的口令，**不是**密钥备注名；
- 模拟盘密钥仅模拟环境可用、实盘密钥仅真实环境可用，两套互不通用；
- 环境选择：手动交易由「合约行情」页的「模拟盘 / 实盘」页签决定；信号自动交易由「模拟盘自动下单 / 实盘自动下单」两个独立开关决定。

## 二、开关类参数（7 项）

### 2.1 OKX 交易（okxEnableTrade）

- **作用**：AI 助手交易权限总开关。开启后 AI 对话可实际下单/撤单（如「用 OKX 市价买入 0.01 BTC」）；关闭时 AI 只能查询行情、持仓、账户等只读信息。
- **注意**：此开关**只管 AI 助手对话**，与信号自动下单无关——信号自动交易只受各自的「模拟盘/实盘自动下单」开关控制。

### 2.2 模拟盘自动下单（okxSignalTradeEnable）

- **作用**：信号监控「OKX 模拟盘池」上报的买卖点信号，自动在 OKX 模拟盘市价下单，**不动真实资金**。
- **信号来源**：池内 `ok:`（OKX）/ `bn:`（币安）/ `bt:`（Bitget）前缀品种的买卖点信号（代码会自动映射到 OKX 合约）。
- **防重复开仓四道闸**：
  1. 同一信号同一分钟去重（同一根 K 线只允许一笔开仓，buy/sell 互相也算）；
  2. 同向已有持仓不加仓；
  3. 止盈/止损平仓后同向冷却（见 5.2）；
  4. 合约不可交易（错误码 51001）后熔断 6 小时。
- **流水状态**：`success`=已成交 / `failed`=失败（含原因）/ `skipped`=正常跳过（如金额低于最小下单量，每合约半小时最多记一条，不刷流水）。

### 2.3 实盘自动下单（okxSignalTradeLive）

- **作用**：与 2.2 同一套机制，作用于「OKX 实盘池」的信号，**动用真实资金**，界面上有红色警示标签。
- **与模拟盘独立**：可同时开启、可各自暂停；模拟盘与实盘是两个独立账户。

### 2.4 自动调池·模拟盘（okxAutoPoolEnable）／ 自动调池·实盘（okxAutoPoolLive）

- **作用**：「趋势跟随」引擎的全局总闸。开启后，监控面板的「趋势跟随」才能运行：定时全市场扫描 OKX 永续，达到入池门槛的自动加入对应监控池；跌破出池线的自动移除。
- **双重确认**：本总闸 + 面板「趋势跟随」开关，**两者都开才生效**；每轮扫描前实时回查总闸，随时可在设置页一键急停。
- **绝不主动平仓**：失趋势但仍有持仓的品种会**暂留池中**，交给买卖点自动交易平仓，平掉后下轮扫描自动移除。趋势跟随只调池、不下单——实盘的真实资金风险全部由「实盘自动下单」一侧承担。
- **处置范围**：只自动处置 `ok:` 前缀品种；跨所品种（`bn:`/`bt:`）不会被自动调池。
- **建议**：先在模拟盘验证出入池节奏，确认后再开实盘总闸。

### 2.5 股票信号下单（okxSignalStockEnable）

- **作用**：股票永续信号（名称带「美股/港股永续」标记，如 SOXL / NVDA 类合约）的独立开关，与加密信号互不影响。
- **现状**：OKX 模拟盘未上架股票永续，**当前暂仅模拟盘语义**；实盘 xStocks 类产品上线后才有实际成交。

### 2.6 止盈止损(持仓)（okxTpSlEnable）

- **作用**：软件侧兜底监控：后台**每 10 秒**分别拉取模拟盘与实盘两个账户的全部持仓，任一持仓达到平仓线立即市价 `reduceOnly` 平仓（只减仓、不加仓）。
- **双保险机制**：与开仓时附带的交易所侧条件单（止盈止损触发价）互补——软件侧算账户收益率口径，交易所侧算价格口径，**谁先到线谁先平**；先触发的一侧平掉后，软件自动撤销另一侧的孤儿条件单。
- **可靠性**：平仓失败自动指数退避重试（60s→2min→…封顶 30min）。
- **强烈建议开启**：关闭后仓位无自动兜底，风险敞口显著放大。

## 三、下单金额（3 项）

### 3.1 下单金额模式（okxSignalTradeAmountMode）

| 选项 | 说明 |
|------|------|
| 固定金额（默认） | 每笔信号按固定金额开仓 |
| 按可用余额比例（仓位） | 每笔按**下单环境账户**可用 USDT × 仓位比例作为名义价值开仓 |

- 比例模式下：模拟盘按模拟盘余额、实盘按实盘余额各自计算，互不干扰；金额随余额实时浮动（盈利后变大、亏损后变小）；余额查询失败或为 0 时该笔落失败流水。
- 模式切换后，固定金额输入框自动禁用/启用。

### 3.2 仓位比例（okxSignalTradeAmountRatio）

- **仅比例模式生效**。选项：`1/4 仓`(0.25) / `1/3 仓`(0.3333) / `1/2 仓`(0.5) / `全仓`(1)。
- **名义价值口径，不随杠杆放大**：本笔名义 = 可用 USDT × 比例；10x 杠杆下实际占用保证金 = 名义 ÷ 10（如 1/3 仓 ≈ 动用 3.3% 余额作保证金）。
- ⚠️ **全仓 + 高杠杆的危险**：连续信号会快速叠加仓位（20x 下每笔保证金只占名义 1/20，余额几乎不消耗），务必配合「防爆仓·最大持仓数」与「最大保证金率」使用。
- 非法/缺失时保守回退 1/4 仓。

### 3.3 每笔金额（模拟盘 okxSignalTradeUSDT / 实盘 okxSignalTradeLiveUSDT / 股票 okxSignalStockUSDT）

- **名义价值口径（不乘杠杆）**：SWAP 按张数换算（张数 = 金额 ÷ 现价 ÷ 每张面值），SPOT 按基础币数量换算（数量 = 金额 ÷ 现价）。
- 20x 杠杆下 SWAP 实际占用保证金 ≈ 名义 ÷ 20——杠杆只影响保证金占用，不影响仓位大小。
- **三个默认值**：模拟盘 **100**、实盘 **10**（保守）、股票 **100**。三者完全独立；实盘请按风险承受能力设置。
- 仅「固定金额」模式生效（比例模式下禁用）。
- 金额低于该合约最小下单量时记 `skipped` 跳过、不算失败。
- 留空/非法时保守回退各自默认值。

## 四、订单与品种（3 项）

### 4.1 信号下单品种（okxSignalTradeInstType）

| 选项 | 说明 |
|------|------|
| 永续合约 SWAP（默认） | 按合约面值换算张数，支持杠杆与交易所侧附带止盈止损 |
| 币币现货 SPOT | 按币种数量下单，无杠杆，最小下单量以交易所规则为准 |

### 4.2 信号下单杠杆（okxSignalTradeLever）

- **仅 SWAP 有效**。选项：账户默认（留空）/ 1x / 2x / 3x / 5x / 10x / 20x。
- 下单前按环境（模拟盘/实盘）设置该合约杠杆（**全仓模式**）；超过合约最大杠杆时自动收敛到上限；**设置失败该笔拒绝下单**（宁可漏单不裸奔杠杆）。
- 杠杆只影响保证金占用，不影响仓位大小（数量始终按名义金额换算）。
- **建议显式设置**：留空 = 不显式设置、沿用账户当前杠杆，此时交易所侧附带止盈止损可能不下发，仅剩软件侧监控兜底。参数模板应用后默认 1x。

### 4.3 交易周期过滤（okxSignalTradeKlts）

- **多选**：1分钟 / 5分钟 / 15分钟 / 30分钟 / 60分钟 / 日线 / 周线。只允许勾选周期的信号自动下单。
- **留空 = 不过滤**（全部周期都会下单，**不推荐**——短周期信号密集、噪声大）。
- **建议只勾选「60分钟」**：回测显示周期越短信号越密集，反复进出的手续费会快速吞噬本金（5m 裸信号日均 4.5 笔/品种，手续费是主要亏损来源）。
- 与信号监控面板的周期含义一致：监控池每只票可配多个监控周期，此处决定哪些周期「有资格触发下单」。

## 五、信号质量与频率过滤（6 项）

> 这组参数决定「哪些信号够格变成订单」。过滤链顺序：周期 → 分数 → 方向 → 顺大势 → 冷却 → 单日上限 → 止盈区间门槛。

### 5.1 最低信号分数（okxSignalTradeMinScore）

- **作用**：买卖点信号为 **14 路指标共振**产生，分数 = 参与共振的路数（满分 14），路数越多越可靠。低于该分数的信号不自动下单。
- **建议 8~10**（≈ 14 路制的 57%~71%，相当于旧 10 路制 6~7 的严格度）。
- ⚠️ **扩路提醒**：满分从 10 变 14 后，旧值 6~7 的实质门槛变松，建议同步上调。
- 留空 / 0 = 不限制。

### 5.2 止盈止损冷却(分钟)（okxSignalTradeCooldownMin）

- **作用**：止盈/止损或反向平仓后，**同合约同方向**在该时长内不再自动开仓，防止震荡行情中被反复止损收割。
- **反向换向不受冷却影响**：平多后仍可立即开空。
- 留空 = 默认 **30 分钟**；显式 0 = 关闭冷却。

### 5.3 开单最低止盈 / 开单最大止盈（okxSignalMinTpPct / okxSignalMaxTpPct）

- **作用**：开仓前按当前止盈止损配置**估算本笔预期止盈收益率**（保证金口径，与止盈线同口径），低于下限或高于上限都不开单——预期止盈必须落在区间内。
- **口径**：固定收益率模式 = 止盈收益率本身；波动率自适应模式 = 平均振幅 × 止盈倍数 × 生效杠杆（杠杆未知按 10x 估算）。
- **为什么要下限**：低波动合约算出的止盈线过近，双边手续费 + 滑点即可吃掉全部毛利。
- **为什么要上限**：vol 模式下振幅过大意味着止损线同样过远、单笔最大回撤远超常规，可过滤极端行情/妖币合约。
- **不拦截的情形**：止盈止损未开启、或未配置止盈时无法估算，不拦截。
- 留空 / 0 = 不限制。

### 5.4 开仓方向（okxSignalTradeDirMode）

| 选项 | 买入信号 | 卖出信号 |
|------|----------|----------|
| 多空都做（默认） | 开多 | 开空 |
| 只做多（卖出信号仅平多） | 开多 | 只用于平掉多头持仓，不开空 |
| 只做空（买入信号仅平空） | 只用于平掉空头持仓，不开多 | 开空 |

- **只做多**：空头行情里长期不出手（既是特点也是取舍）；5m/15m 实测「只做多」在下跌季度回撤更小。

### 5.5 顺大势门控（标的自身 1H）（okxSignalTradeRegime）

- **作用**：按**标的自身** 1 小时线趋势（EMA 体系）过滤逆势单——多头趋势只开多、空头趋势只开空、多空过渡区不限制。
- **为什么**：减少下跌段错误做多、上涨段错误做空这类逆势亏损单。15m ≥6 路信号的历史回测中，顺大势是全部参数组合中对年化改善最大的一项。
- 每个标的按自己的 1H 判定，与其他标的无关（股票类合约必须用这种「标的自身」模式，用 BTC 当趋势代理会反向）。

### 5.6 单合约单日开仓上限（okxSignalTradeMaxPerDay）

- **作用**：同一合约单个自然日（UTC+8）累计**成功开仓**笔数达到上限后，当日不再对该合约自动开仓。
- **为什么**：避免同一波行情被反复进出、手续费不断累积；短周期信号尤其需要。
- 留空 / 0 = 不限制。建议 2 左右。

## 六、防爆仓风控（2 项）

> 开仓前最后一道闸，只拦开仓，不影响平仓/止盈止损。

### 6.1 防爆仓·最大持仓数（okxRiskMaxPositions）

- **作用**：当前环境账户**非零持仓笔数 ≥ 上限**时拒绝开新仓。防止连续信号在几分钟内累加成超额仓位。
- 默认 **3**；0 = 不限制；模拟盘与实盘各自计数、互不干扰。
- 拒单提示格式：`已达最大并发持仓数 5/3`——斜杠前是**当前持仓数**、后是**上限**，别看错。

### 6.2 防爆仓·最大保证金率(%)（okxRiskMaxMarginRatio）

- **作用**：**维持保证金合计 ÷ 总权益 ≥ 阈值(%)** 时拒绝开新仓——这是距离强制平仓最直接的指标，越接近 100% 越危险。
- 默认 **30**；0 = 不限制；模拟盘与实盘各自按各自账户计算；建议配合止盈止损一起使用。

> 空值保障：这两个参数清空输入框保存时会自动规范化回默认值，不会把空值写库；后端读到空/非法值也一律保守回退。

## 七、止盈止损参数（7 项）

### 7.1 平仓线模式（okxTpSlMode）

| 模式 | 说明 |
|------|------|
| 固定收益率(%) | 用 OKX 保证金收益率 `uplRatio`（含杠杆、多空同号）与固定百分比比较，所有合约共用一组阈值 |
| 波动率自适应（推荐） | 按各合约近 N 根参考周期 K 线的平均振幅（(high−low)/open）动态缩放平仓线：波动大的自动放宽、波动小的自动收紧，避免固定百分比对不同合约失配 |

两种模式的阈值参数模拟盘/实盘**共用**。

### 7.2 固定收益率模式的两个参数

**止盈收益率(%)（okxTakeProfitPct）**
- 保证金口径（含杠杆）：如 5 表示持仓浮盈达 **+5%** 平仓（20x 杠杆下约等于价格涨 0.25%）；多空同号。
- 0 / 留空 = 不启用固定止盈。

**止损收益率(%)（okxStopLossPct）**
- 如 3 表示持仓浮亏达 **-3%** 平仓（20x 下约等于价格反向波动 0.15%）。
- ⚠️ 高杠杆下固定止损百分比非常贴近成本区，容易在正常波动中被扫出场；建议改用波动率自适应模式。
- 0 / 留空 = 不启用固定止损（风险自负）。

### 7.3 波动率自适应模式的四个参数

**波动率参考周期（okxTpSlVolKlt）**
- 取该周期近 N 根 K 线算平均振幅作为缩放基准。默认 15m。
- **实际生效下限 15 分钟**：5m 及更短周期振幅噪声大、阈值抖动且常算出过窄止损线；1H 以上又过于迟钝，15m 是折中。

**回看K线根数（okxTpSlVolBars）**
- 参与平均振幅计算的 K 线根数，默认 **20**；实际按 N+1 根取数（含当前未收线一根），振幅缓存 5 分钟。
- 合法范围 3~300（>2 且 ≤300 才认）。根数越多振幅越平滑、平仓线越稳定。

**止盈倍数（okxTpSlTpMult）**
- 止盈线 = 平均振幅 × 止盈倍数（价格口径；账户口径阈值 = 该值 × 持仓杠杆）。默认 **1.5**。
- **默认搭配移动止盈**：账户浮盈 ≥ 20% 后开始跟踪峰值、从峰值**回吐一半**即平仓（价格门槛 = 20% ÷ 实际杠杆），避免利润过早离场。
- 填 0 = 关闭固定止盈，只保留移动止盈与止损（回测：止盈在 5m/15m/1h 上都会压低总收益，允许只止损是有意义的配置）。

**止损倍数（okxTpSlSlMult）**
- 止损线 = 平均振幅 × 止损倍数。默认 1，**建议 ≥8**（约 8 倍平均振幅）。
- **为什么放大**：倍数越小止损线越窄、越容易被盘中噪声扫出场——实测 5m×20 根得出的止损线常落进手续费+滑点成本区，止损笔数远超止盈。
- **账户口径下限 10%**：价格止损线最低 = 10% ÷ 持仓实际杠杆（10x → 价格 1%、1x → 价格 10%），保证不同杠杆下账户最大亏损一致。
- 非法/缺失时回退默认 1。

## 十、常见问题

**Q1：改了设置为什么没生效？**
① 是否点了「保存」并看到保存成功提示；② 运行中的应用是否为最新构建（后端改动需重新编译）；③ 拒单流水里的数字是库里真值，以它为准。

**Q2：「已达最大并发持仓数 5/3」什么意思？**
当前持仓 5 笔 / 上限 3。想放开就把「防爆仓·最大持仓数」调大（0=不限制）并保存。

**Q3：为什么很多信号显示 skipped？**
常见原因：金额低于合约最小下单量（skipped 不算失败，每合约半小时最多记一条）。把每笔金额调大即可。

**Q4：固定止损 3% 为什么老是被扫？**
高杠杆下固定百分比止损离成本太近。改用「波动率自适应」模式并把止损倍数放大到 ≥8。

**Q5：交易所条件单和软件止盈止损会重复平仓吗？**
不会。双保险谁先到线谁先平，先触发的一侧平掉后软件自动撤销另一侧的孤儿条件单。

**Q6：比例模式为什么金额每笔不一样？**
按「下单瞬间该环境账户可用 USDT × 比例」实时计算，随盈亏浮动；余额查询失败该笔落失败流水。

**Q7：顺大势开着，为什么下跌中还是开了空单？**
标的自身 1H 处于空头趋势时开空是顺大势的正确行为；只有「过渡区」不限制方向。若想完全不做空，用「只做多」。

**Q8：股票信号开了为什么模拟盘没成交？**
OKX 模拟盘未上架股票永续合约，属正常 skipped/failed；实盘 xStocks 类产品上线后才有实际成交。

**Q9：自动调池总闸开了，池子为什么还有失趋势的品种？**
失趋势但仍有持仓的品种会暂留池中（等买卖点自动交易平仓，平掉后下轮扫描自动移除）——趋势跟随绝不主动平仓。无持仓的失趋势品种才会直接移除。

**Q10：冷却时间和单日上限针对谁？**
冷却针对「同合约 + 同方向」；单日上限针对「同合约」（按 UTC+8 自然日、只数成功开仓）。两者都只拦开仓，不影响平仓。
