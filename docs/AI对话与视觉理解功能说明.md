# AI 对话与视觉理解功能使用说明

本文介绍 AI 助手对话（Agent 模式）与视觉理解（图片对话）两项功能的使用方法。

---

## 一、AI 对话

### 1. 功能入口

点击页面右侧悬浮的 **AI 助手** 按钮，打开对话面板。对话基于 Agent 架构，可自动调用行情查询、龙虎榜、板块资金流、复盘策略等内置工具，直接在对话中完成选股分析、盘面解读等复杂任务。

### 2. Agent 模式

对话底部可切换分析模式，选择会自动记忆，下次打开自动恢复：

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| 🤖 自动选择 | 按问题复杂度自动选择模式 | 日常使用，无需纠结选哪种 |
| ⚡ 快速模式 | 单轮工具调用，响应最快 | 简单查询：股价、涨跌幅、单只股票资讯（推荐 DeepSeek 最新版） |
| 🧠 规划模式 | 先制定计划再分步执行 | 多步骤分析：多只股票对比、按条件筛选（推荐 GLM 最新版） |
| 🔬 DeepAgents | 内置任务规划与子 Agent 委派 | 复杂深度研究：行业分析、全维度个股研报（推荐 Claude / GLM 最新版模型） |

### 3. 技能调用

在输入框输入 `/` 可唤起技能菜单，按名称搜索并选择技能（可多选），选中技能随消息一起提交，AI 将按技能中的专业方法论进行分析。回车 / 点击选择或取消，`Esc` 关闭菜单。

### 4. 其他操作

- **新对话**：面板顶部新建会话；历史会话可在会话列表中切换。
- **中断**：回答生成中可点击「中断」按钮随时停止。
- **参数配置**：对话底部还可切换 AI 模型、系统提示词、思考模式、记忆模式等。

## 二、视觉理解（图片对话）

开启后可直接向 AI 发送图片：截图问股、K 线图分析、持仓截图解读、研报图表提问等。

### 1. 开启方式（前提条件）

1. 进入 **设置 → AI 模型服务配置**；
2. 新建或编辑一条 AI 配置，打开 **视觉理解** 开关；
3. 该配置需绑定支持视觉的模型（如 GLM-4V、Qwen-VL、GPT-4o、Claude、Gemini 等多模态模型）；
4. 保存后在对话底部切换到该配置即可。

> 未开启时，对话输入框旁的图片按钮为灰色不可点，悬停提示"当前模型未开启视觉理解"。

### 2. 添加图片的三种方式

- **上传本地图片**：点击输入框左侧图片按钮 → 「上传本地图片」，支持多选；
- **输入图片链接**：点击图片按钮 → 在链接框粘贴 `https://...` 图片地址 → 「添加」；
- **直接粘贴**：截图后在输入框 `Ctrl + V` 粘贴。

添加后图片显示在输入框上方，上传中会显示转圈状态，鼠标悬停缩略图可点击 × 移除，随文字一起发送。

### 3. 图片限制

- 格式：JPEG / PNG / GIF / WebP
- 大小：单张 ≤ 8MB
- 数量：最多 10 张

### 4. 本地图片的托管机制（重要）

本地图片默认自动上传到免费公共图床转为外链发送；图床不可用或上传失败时，自动回退为 base64 直传。

> ⚠️ 图床为公共免费服务，**请勿上传含敏感信息（账户、持仓成本、身份证件等）的图片**，敏感图片建议先打码。

### 5. 模型兼容性

各主流模型供应商已自动适配，用户无需关心差异：

- OpenAI 系（含 DeepSeek-Vision、Qwen-VL、火山方舟、OpenRouter、硅基流动等）：外链直接下发；
- Claude：base64 自动拆解适配；
- Gemini / Ollama：外链由后端自动下载转为 base64 后下发。

### 6. 注意事项

- **历史消息中的图片不会重发**：会话记忆仅保存文字内容，追问涉及之前的图片时，请重新发送该图片；
- 若当前配置未开启视觉理解而发送了图片，AI 会回复"图片已被忽略"的提示，按上文开启开关即可。

## 三、常见问题

**Q：图片按钮是灰色的点不了？**
当前选中的 AI 配置未开启视觉理解。到「设置 → AI 模型服务配置」中为该配置打开视觉理解开关，或切换到已开启的配置。

**Q：发送图片后 AI 说自己看不到图？**
1. 确认配置的模型本身支持视觉（普通纯文本模型无法理解图片）；
2. 查看应用日志（info.log）中是否有 `vision: 下发 N 张图片` —— 无此行说明图片未到达后端，可尝试重新发送；
3. 图片过大可能导致上传图床超时，可压缩后重试。

**Q：粘贴图片没反应？**
仅支持粘贴剪贴板中的图片数据（如截图），从文件管理器复制的文件对象不支持粘贴，请使用「上传本地图片」。

**Q：DeepSeek 模型能用图片吗？**
deepseek-chat 为纯文本模型不支持；使用 DeepSeek 接口时请绑定支持视觉的模型并开启视觉理解开关。
