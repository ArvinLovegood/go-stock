## 1. 软件简介

go-stock 是一款基于大语言模型的 AI 赋能股票分析桌面工具，基于 **Wails + Vue3 + NaiveUI** 技术栈构建，支持 A股、港股、美股的行情数据获取与智能分析。

### 1.1 核心特性

- 多市场行情监控（A股/港股/美股）
- AI 智能分析股票（支持 16 个大模型平台）
- AI 智能体对话（React / PlanExecute / DeepAgents 三种模式）
- 浮动 AI 助手（任意页面快速唤起对话）
- 实时 K 线图与分时图（ECharts + TradingView Lightweight Charts）
- 专业 K 线绘图工具（测量/波浪理论/13种绘图工具）
- K 线复权切换（前复权/不复权/后复权）
- 分时成交与分笔成交明细查询
- 集合竞价明细与个股资金流向查询
- 市场资讯聚合（财联社/新浪/外媒/雪球）
- 资金流向（个股/板块/概念）与龙虎榜数据
- 涨停梯队与异动监控
- 社区化提示词广场与问答广场
- MCP 服务与技能扩展
- 定时任务与自动预警（5种预警类型）
- 交易日志管理（含当日盈亏/收益统计）
- 每日操作计划（多情景预案 + 盘中自动预警）
- 弹幕互动社区
- 钉钉推送 / 飞书应用机器人 / 本地通知
- 概念标签管理（多标签/筛选/新建）
- 场内 ETF 基金搜索与多周期 K 线

### 1.2 支持的 AI 模型平台

DeepSeek、硅基流动、智谱AI、字节豆包、阿里云百炼、Moonshot、腾讯混元、讯飞星火、零一万物、MiniMax、百川智能、百度千帆、OpenAI、Azure OpenAI、OpenRouter、Ollama 以及所有兼容 OpenAI API 格式的平台。

新增国内主流订阅制套餐接口地址（火山引擎 Ark Plan/Coding、腾讯云 lkeap plan、阿里云百炼套餐等），套餐接口需配套专属 API Key（通常 `sk-sp-` 开头）。

### 1.3 数据来源

| 数据来源 | 用途 |
|----------|------|
| 东方财富 | 行情数据、资金流向、财报数据、龙虎榜、K线 |
| 同花顺问财 | 自然语言选股、行情查询、研报搜索 |
| 新浪财经 | 财经新闻、基金数据 |
| 财联社 | 实时市场电报快讯 |
| 雪球 | 热门事件、股票讨论 |
| 华尔街见闻 | 外媒资讯、市场日历 |
| TradingView | 国外财经媒体、K线数据 |
| 通达信 (gotdx) | K线、分时成交、分笔明细、集合竞价、资金流向（MAC 主客户端 + MAC Ex 扩展行情） |

## 2. 安装与启动

### 2.1 下载软件

从 GitHub Releases 页面下载对应版本的安装包：

- Windows 版：`go-stock-windows-amd64.exe`
- macOS 版：`go-stock-darwin-universal`

### 2.2 首次启动

1. 双击运行程序
2. 首次启动会自动初始化股票基础数据（A 股/港股/美股基础信息，含场内 ETF）
3. 窗口大小会自适应屏幕分辨率
4. 加载完成后进入主界面

### 2.3 数据存储

- 数据库文件：运行目录下 `data/stock.db`（SQLite）
- 字典数据：运行目录下 `data/` 目录
- 配置信息保存在本地数据库中

### 2.4 卸载

Windows 卸载逻辑已优化，会保留用户数据（自选股、分组、配置等），便于版本回滚或重装。

## 3. 界面布局与导航菜单

### 3.1 整体布局

软件采用**底部水平导航栏 + 上方内容区**的布局方式，导航菜单固定在窗口底部。下拉菜单支持最大高度 60vh 自动滚动。

### 3.2 导航菜单结构

| 菜单项 | 路由 | 说明 |
|--------|------|------|
| ⭐ 股票自选 | `/` | 自选股管理，含分组子菜单 |
| 📰 市场行情 | `/market` | 市场数据与资讯，含13个子菜单 |
| 📊 K线分析 | — | 独立 K 线分析工具（需 VIP2 及以上） |
| ✨ 基金自选 | `/fund` | 基金自选 + 基金排行（需启用） |
| 🤖 AI智能体 | `/agent` | AI智能体对话（需启用） |
| 🔬 研究中心 | `/research` | 研究分析工具集，含13个子菜单 |
| ⚙️ 设置 | `/settings` | 基础设置 + AI模型服务 |
| 🐙 关于 | `/about` | 版本信息与赞助 |
| 隐藏至托盘区 | — | 最小化到系统托盘 |
| 退出程序 | — | 关闭应用 |

> ⚠️ 注意：「基金自选」和「AI智能体」两个菜单项需要在后台配置中启用对应功能后才会显示。「K线分析」需要 VIP2 及以上赞助用户才能进入，权限不足时点击会弹出升级提示且不跳转。

### 3.3 窗口标题栏

标题栏动态显示当前市场状态，格式为：

```
go-stock A股交易中|港股休市|美股休市  「投资格言」  [数据来源于网络，仅供参考；投资有风险，入市需谨慎]
```

市场状态每 60 秒自动刷新，同时随机切换一条投资格言。

### 3.4 滚动快讯条

当在设置中启用"显示滚动快讯"后，页面顶部会以跑马灯形式滚动显示市场快讯标签。

### 3.5 水印

软件界面叠加有水印层，用于数据来源声明和防伪标识。

## 4. 股票自选

股票自选是软件的核心页面，用于管理和监控关注的股票。

### 4.1 标签页分组

页面顶部为标签页栏，支持分组管理自选股。顶部页签已固定（sticky），滚动时不被遮挡。

| 操作 | 说明 |
|------|------|
| 点击"全部" | 查看所有自选股（表格视图，支持分页/排序/搜索/筛选） |
| 点击分组标签 | 查看该分组内的股票（卡片视图） |
| 点击"+"按钮 | 新增分组（输入分组名称和排序值） |
| 点击分组标签「重命名」按钮 | 修改分组名称 |
| 点击标签关闭按钮 | 删除分组（需二次确认，数据不可恢复） |
| 拖拽标签 | 调整分组排序（"全部"标签不可拖拽） |

分组列表会在启动时从数据库动态加载，每个分组作为"股票自选"菜单的子菜单项显示。

### 4.2 「全部」标签页（表格视图）

「全部」标签页使用 NDataTable 表格组件展示，支持以下功能：

- **客户端分页**：默认每页 50 条，可选 10/20/50/100，总数小于等于 pageSize 时隐藏分页器
- **列排序**：价格、涨跌幅、分组、概念等列支持升降序排序
- **关键字搜索**：按股票名称/代码模糊匹配
- **分组筛选**：通过下拉框筛选属于指定分组的股票
- **概念筛选**：通过下拉框筛选属于指定概念的股票
- **默认排序**：按涨跌幅降序

表格列包含：股票名称/代码、当前价、涨跌幅、最高/最低/昨收/今开、分组（NTag 多标签）、概念（NTag 多标签）、操作列。

操作列按钮：取消关注、AI分析、移出分组、设置分组、设置概念、成交明细、详情、公告、研报、多周期K线。

### 4.3 概念标签系统

每只股票可挂载多个概念标签（与分组系统独立共存，不影响页签）：

| 操作 | 说明 |
|------|------|
| 在表格操作列点击「设置概念」 | 弹出下拉菜单，勾选/取消已有概念 |
| 下拉菜单「新建概念」 | 输入名称创建新概念并加入该股票 |
| 顶部「概念筛选」下拉 | 按概念筛选表格数据（首项为"全部概念"） |
| 大小写去重 | 输入 `ai` 时若已存在 `AI` 则复用现有标签 |

概念标签在表格的「概念」列以 NTag（info 类型）形式展示，无概念的股票显示「—」。

### 4.4 分组标签页（卡片视图）

非「全部」标签页的分组页仍采用卡片视图。每只自选股以卡片形式展示，包含以下信息区域：

#### 卡片标题区

- **股票代码标签**：显示股票代码
- **取消关注**按钮：移除该股票
- **AI分析**按钮：发起 AI 智能分析（需启用 AI 功能）
- **移出分组**按钮：将股票从当前分组移出（仅在分组标签下显示）

#### 价格信息区

- **当前价格**：实时价格，涨为红色，跌为绿色，平为默认色
- **盘前盘后价格**：仅美股显示盘前盘后价格及涨跌幅
- **涨跌幅百分比**：带数字动画效果
- **今日盈亏金额**：仅在设置了成本价和持仓数量后显示
- **迷你走势线**：仅在分组标签下显示

#### 行情数据区

四宫格显示：最高价+最高涨幅百分比、最低价+最低跌幅百分比、昨日收盘价、今日开盘价

#### 盘口数据区（仅A股）

可折叠面板，展示买卖五档盘口数据。折叠时显示买一报价(申报量)/卖一报价(申报量)，展开后显示买一至买五、卖一至卖五各档的报价和申报量。

#### 卡片底部

- 日期和时间
- 持股数量标签（设置持仓后显示）
- 成本盈亏标签："成本:xxx*xxx 盈亏% (xxx ¥)"
- **多周期K线**按钮

#### 卡片操作按钮

| 按钮 | 功能 |
|------|------|
| 成本 | 打开成本设置对话框 |
| 分时 | 打开分时走势图 |
| 日K | 打开日 K 线图 |
| 资金 | 打开资金趋势图（仅A股显示） |
| 明细 | 打开分时成交 + 分笔成交明细对话框 |
| 详情 | 跳转问财搜索页面 |
| 公告 | 跳转公司公告页面（仅A股） |
| 研报 | 跳转个股研报页面（仅A股） |
| 设置分组 | 下拉菜单，将股票添加到指定分组（支持新建分组） |
| 设置概念 | 下拉菜单，管理股票概念标签 |

### 4.5 底部搜索栏

位于页面右下角，包含：

- **自动完成输入框**：输入股票名称/代码/指数关键词，实时模糊匹配（含场内 ETF）
- **关注**按钮：将搜索到的股票添加到自选列表
- **发送弹幕**按钮（需启用弹幕功能）：通过 WebSocket 发送弹幕消息

> 💡 提示：搜索已关注的股票时，页面会自动滚动到对应卡片并闪烁红色边框5秒。

### 4.6 成本设置对话框

点击"成本"按钮打开，宽度800px，表单字段：

| 字段 | 说明 |
|------|------|
| 股票成本 | 成本价，支持 HK$/¥ 后缀自动适配 |
| 股票数量 | 持仓数量，步进100 |
| 涨跌提醒 | 涨跌幅预警百分比 |
| 股价提醒 | 绝对价格预警 |
| 开仓价 | 开仓价位 |
| 股票排序 | 排序值 |
| 止盈价 | 止盈价格 |
| 止损价 | 止损价格 |

### 4.7 分时图对话框

点击"分时"按钮打开，宽度1000px：

- 使用 ECharts 绘制当日分时走势图
- 包含股价线和成交量柱状图
- 标记最高/最低价位点
- 标记均价线、开盘价线、收盘价线
- 低于开盘价（绿色）、大于开盘价小于收盘价（蓝色）、大于收盘价（红色）分段着色
- **自动刷新**：打开后每 10 秒自动刷新

### 4.8 日K线图对话框

点击"日K"按钮打开，宽度1000px：

- 日K蜡烛图
- MA5/MA10/MA20/MA30 均线
- 成交量柱状图
- 数据缩放滑块，默认显示近14%的数据
- 标记最高/最低/平均收盘价
- 鼠标悬停提示框（开盘/收盘/最低/最高/成交量/各均线值）
- 数据来源：近365天K线数据

### 4.9 分时成交与分笔明细对话框

点击卡片"明细"按钮或表格操作列"成交明细"按钮打开，基于 gotdx 协议获取真实分笔成交数据：

#### 分时走势图（顶部）

- ECharts 折线图：股价线 + 均价线 + 成交量柱状图
- **多日模式**：可切换日期范围（最近交易日为终点），多日时 x 轴显示 `MM-DD HH:MM`，单日时显示 `HH:MM:SS`
- 历史日期自动调用 `GetHistoryTdxMinuteTimeData`，今日调用 `GetTdxMinuteTimeData`
- 非交易日数据自动跳过，默认日期为最近交易日
- 支持手动刷新

#### 分笔成交明细表（底部）

- NDataTable 分页表格，时间倒序（最新在前），多日模式自动插入「日期」列
- 字段：时间、价格、涨跌（颜色标记）、成交量、买卖方向（买/卖/中性 着色）
- **档位统计**：基于全量成交数据计算大单/中单/小单分布
- **净流入折线图**：与分时图 x 轴对齐
- 全量拉取：A股循环分页每页500条、港美股每页1000条，确保档位统计与净流入计算基于完整数据
- 数据顺序：底层升序（供统计），表格显示倒序

#### 数据源路由

- A股：标准协议（gotdx.New 主行情客户端，StockAuction/StockHistoryTickChart）
- 港美股：MAC 协议（gotdx.NewMAC 主客户端端口7709，MACAuction/ExTickChart）
- 系统按 `tdxMarketFromStockCode` 自动路由

### 4.10 AI分析对话框

点击"AI分析"按钮打开，宽度800px：

- Markdown 格式渲染 AI 分析结果，加载状态旋转动画，导出 PDF 工具栏
- 底部信息：模型名称标签 + 分析时间 + 风险提示
- 工具调用开关 / 思考模式开关
- 三个下拉选择框：AI 模型服务配置、系统提示词、用户提示词
- 问题输入框：自定义提问内容

| 按钮 | 功能 |
|------|------|
| 开始AI分析 | 重新发起 AI 流式分析 |
| 保存为图片 | 截图保存为 PNG |
| 复制到剪切板 | 复制分析结果文本 |
| 保存为Markdown | 保存为 `.md` 文件 |
| 保存为Word | 导出为 `.docx` 文件 |
| 分享到项目社区 | 分享到社区 |

### 4.11 资金趋势对话框

点击"资金"按钮打开，宽度1000px，使用 MoneyTrend 组件展示近 360 天资金趋势图，图表高度 500px。

### 4.12 多周期K线对话框

点击"多周期K线"按钮打开，最大宽度 1100px：

- 使用轻量级 K 线图组件（TradingView Lightweight Charts）
- 支持拖拽调整开仓价/止损价/止盈价/成本价线，调整后自动保存
- 工具栏内嵌「关注/取消关注」按钮（含新建分组入口）
- 支持复权类型切换、测量、波浪、绘图工具（详见第 5 章）

> ⚠️ 注意：VIP权限控制：VIP2 及以上用户可正常使用，权限不足时提示并自动关闭。美股代码（`gb_` 前缀）不支持多周期K线。

### 4.13 价位线预警系统

每次价格更新时自动检查：

| 预警类型 | 触发条件 | 推送类型 |
|----------|----------|----------|
| 涨跌幅预警 | 涨跌幅达到设定百分比 | 类型1 |
| 股价预警 | 股价触及设定价格 | 类型2 |
| 成本价预警 | 成本盈亏达到设定值 | 类型3 |
| 止盈触及 | 当前价 ≥ 止盈价 | 类型4 |
| 止损触及 | 当前价 ≤ 止损价 | 类型5 |

防抖机制：同一价格不重复提醒，两次通知间隔至少60秒。

### 4.14 弹幕系统

- 连接 WebSocket 服务器实时接收弹幕
- 使用 vue3-danmaku 组件展示弹幕飘过效果
- 可在设置中开启/关闭弹幕功能

## 5. K线分析

K 线分析是独立菜单项，提供专业级 K 线图表分析工具，包含完整的复权切换、测量、波浪理论、绘图工具等能力。

> ⚠️ 注意：本功能需 VIP2 及以上赞助用户使用，权限不足时菜单点击会弹出升级提示且不跳转。

### 5.1 图表组件

基于 TradingView Lightweight Charts 实现，包含：

- 多周期切换：分时/5分钟/15分钟/30分钟/60分钟/日K/周K/月K/季K/年K
- MA5/MA10/MA20/MA30 均线
- 成交量柱状图
- 数据缩放滑块
- 鼠标十字光标 + 悬停提示框

### 5.2 复权类型切换

| 复权类型 | 说明 |
|----------|------|
| 前复权 (qfq) | A股默认；以最新价格为基准向前调整历史价格 |

- **GetStockCallAuction**：集合竞价明细查询，A股走主行情客户端，港美股走MAC主客户端

- **AddDailyOperationPlan**：每日操作计划生成，AI 输出多情景方案（触发价区间/止损价/目标价）+ 操作纪律并结构化保存，支持开启盘中预警（止损/情景触发/目标达成四类条件自动通知）

### 8.5 流式响应

- AI 回复以流式方式逐字展示
- 支持 `[STEP]` 标记的执行步骤展示
- 支持工具调用信息展示（函数名+参数）
- 自动检测内容中的 JSON 并提取为"分析报告"
- 每 1.5 秒定时格式化 Markdown
- 修复了 React 模式下竞态条件导致最终结果不显示的问题

### 8.6 PlanExecute 模式详解

PlanExecute 模式采用 Planner→Executor→Replanner 管道，最大迭代7次。AI 首先制定分析计划，然后逐步执行每个步骤，执行完成后重新评估是否需要调整计划。系统对执行结果进行智能压缩：最近步骤获得更多预算，较早步骤预算减少，确保关键信息不丢失。

### 8.7 其他交互

- **回到底部**：悬浮按钮，滚动时自动出现
- **停止生成**：中断 AI 回复
- **复制操作**：复制消息内容
- **暗黑主题**：自动跟随系统配置

### 10.12 每日操作计划

每日操作计划是结构化的盘中交易预案，针对单只股票在指定日期的操作方案，支持多情景预案、操作纪律和盘中自动预警。可手动新建，也可由 AI 智能体自动生成。

#### 数据结构

每条计划包含以下字段：

| 字段 | 说明 |
|------|------|
| 计划日期 | YYYY-MM-DD，默认当天 |
| 股票代码 / 名称 | 计划标的，支持 A股 / 港股 / 美股（如 `603986.SH`、`00700.HK`） |
| 总体判断 | 对该股当日走势的综合研判 |
| 情景方案 | 多情景预案数组（至少 1 个），每个情景包含触发条件、动作、仓位、买入区间、止损价、第一/第二目标价、策略说明 |
| 操作纪律 | 纪律数组（至少 1 条），含原则与说明（如「仓位控制 — 首次建仓不超过总计划资金的1/3」） |
| 一句话总结 | 计划核心结论 |
| 风险提示 | 默认含高波动品种风险声明 |
| 状态 | 待执行(pending) / 执行中(executing) / 已完成(completed) / 已过期(expired) |
| 开启盘中预警 | 开关，开启后盘中触及价位自动通知 |
| 通知渠道 | 软件内提醒(app) / 飞书(feishu) / 钉钉(dingding)，可多选 |

#### 情景方案字段

每个情景方案支持文本描述 + 量化字段两部分：

| 文本字段 | 量化字段（盘中预警用） |
|----------|----------------------|
| 买入区间（如 `460-470元`） | 触发价下限/上限 triggerPriceMin/Max |
| 止损价（如 `400元`） | 止损价数值 stopLossPriceNum |
| 第一目标（如 `500-505元`） | 目标1下限/上限 target1Min/Max |
| 第二目标（如 `550-560元`） | 目标2下限/上限 target2Min/Max |

> 💡 文本框失焦时系统自动从价格文本解析数值填入量化字段（仅填充空值，不覆盖已填值），如输入 `460-470元` 会自动填充触发价下限=460、上限=470。

动作类型（ActionType）与标签颜色：

| 动作 | 标签颜色 | 说明 |
|------|----------|------|
| 买入 (buy) | 绿色(success) | 建仓 / 加仓 |
| 观望 (wait) | 橙色(warning) | 暂不操作 |
| 观察 (observe) | 蓝色(info) | 持续跟踪 |
| 止损 (stop_loss) | 红色(error) | 离场止损 |

#### 列表与查询

- 分页展示（每页 10/20/50 条），按计划日期倒序
- 支持按股票代码、股票名称、计划日期、状态组合筛选
- 列表实时拉取计划内股票的当前价与涨跌幅

#### 操作功能

| 操作 | 说明 |
|------|------|
| 新增 / 编辑 | 弹窗表单，情景方案与操作纪律支持动态增删（至少保留 1 个） |
| 查看 K 线 | 弹出轻量级 K 线图（StockLightweightKlineChart） |
| 查看成交明细 | 弹出分时走势 + 分笔成交表，含超大/大/中/小单档位统计与净流入折线图 |
| 更新状态 | 手动切换 待执行 / 执行中 / 已完成 / 已过期 |
| 预警开关 | 一键开启/关闭该计划的盘中预警 |
| 删除 | 移除计划 |

#### AI 自动生成

AI 智能体可通过 `AddDailyOperationPlan` 工具自动生成结构化操作计划。当用户提问包含「操作计划」「每日计划」「操作方案」「明日操作」「盘中预警」等关键词时，系统自动匹配该工具分组，AI 会输出多情景方案、操作纪律并结构化保存。

#### 盘中预警监控

开启预警的计划在交易时间内（A/港/美任一市场开市）自动监控，每只情景方案按以下 4 类条件触发通知：

| 预警类型 | 触发条件 | 去重策略 | 通知建议 |
|----------|----------|----------|----------|
| 止损预警 | 实时价 ≤ 止损价 | 30 分钟去重 | ⛔ 严格执行止损纪律，无条件离场 |
| 情景触发 | 实时价进入触发价区间 | 离开区间后重新进入才再次推送 | 按计划动作 / 仓位执行 |
| 第一目标达成 | 实时价 ≥ 第一目标下限 | 当日只推送一次 | 💡 建议按计划减仓 1/2 |
| 第二目标达成 | 实时价 ≥ 第二目标下限 | 当日只推送一次 | 💰 建议按计划全部止盈 |

通知按计划配置的渠道发送：软件内提醒（系统通知 + 前端快讯红色推送）、飞书、钉钉。止损触发后该情景不再判断其他条件。

> 💡 推荐组合：软件内提醒（盘中即时）+ 飞书（移动端接收），配合定时任务盘后生成次日计划，形成「计划 → 盘中预警 → 复盘」闭环。

## 13. 使用技巧与最佳实践

本章汇总 go-stock 各核心功能的实战使用技巧，帮助您更高效地完成日常行情监控、AI 分析与交易决策。

### 13.1 自选股管理技巧

#### 13.1.1 分组 + 概念双维度管理

go-stock 提供「分组」和「概念」两套独立的标签体系，建议按以下维度划分：

| 维度 | 用途 | 示例 |
|------|------|------|
| 分组 | 产生页签，按"持仓策略"或"关注程度"分类 | 长线持仓、短线观察、打新、指数跟踪 |
| 概念 | 不产生页签，按"主题赛道"分类 | AI、半导体、新能源、医药、央企改革 |

**操作技巧**：

- 一只股票可同时属于多个分组 + 多个概念，例如「贵州茅台」可加入「长线持仓」分组 + 「白酒/消费/沪港通」概念
- 在「全部」标签页通过「分组筛选」+「概念筛选」下拉组合，可以快速定位某一策略 + 某一赛道的标的
- 概念名输入 `ai` 时若已存在 `AI`，系统会自动复用，避免大小写产生重复
- 分组支持「重命名」，概念暂不支持重命名（可在设置概念下拉中通过新建+移除旧标签的方式替代）

#### 13.1.2 「全部」表格视图高效操作

- 默认按涨跌幅降序，便于一眼看到当日最强/最弱标的
- 点击列标题可切换升/降序，再点击取消排序
- 当总数 ≤ pageSize 时分页器自动隐藏，避免冗余 UI
- 搜索框支持股票名称/代码模糊匹配，搜索后回到第 1 页

#### 13.1.3 顶部页签固定

股票自选顶部页签已 sticky 固定，向下滚动卡片时页签始终可见，可随时切换分组而不需要回到顶部。

### 13.2 预警功能使用技巧

#### 13.2.1 五种预警类型组合策略

go-stock 提供 5 种价位线预警类型，建议组合使用：

| 预警类型 | 推荐使用场景 |
|----------|--------------|
| 涨跌幅预警（类型1） | 短线波动监控，例如 ±5% 即时通知 |
| 股价预警（类型2） | 关键价位突破，例如压力位/支撑位 |
| 成本价预警（类型3） | 持仓盈亏管理，例如盈利 10% 通知减仓 |
| 止盈触及（类型4） | 配合计划卖单，到价即提示操作 |
| 止损触及（类型5） | 风险控制，破位即提示止损 |

**配置位置**：股票自选卡片 → 成本按钮 → 成本设置对话框。

#### 13.2.2 防抖机制说明

- 同一价格不重复提醒，避免价格在阈值附近震荡导致刷屏
- 两次通知间隔至少 60 秒
- 仅在交易时间内运行软件才会触发预警

#### 13.2.3 多渠道通知配置

预警触发后，可同时通过以下渠道推送：

| 渠道 | 适用场景 | 配置位置 |
|------|----------|----------|
| 本地推送 | 在电脑前工作 | 设置 → 通知设置 → 本地推送 |
| 钉钉机器人 | 团队/群组共享 | 设置 → 通知设置 → 钉钉推送 + Webhook 地址 |
| 飞书应用机器人 | 手机端随时接收 + AI 问答 | 设置 → 通知设置 → 飞书应用机器人 + App ID/Secret |

> 💡 推荐组合：本地推送（即时）+ 飞书机器人（移动端），既不漏消息又能在手机上直接追问 AI。

#### 13.2.4 飞书机器人使用要点

- 回答内容超过 500 字 / 含代码块 / 含表格分隔行 / 超过 20KB 时自动转图片回复
- 图片回复失败会自动降级为卡片回复，保证可用性
- 飞书卡片协议已升级至 2.0，支持 @所有人 语法
- 可在手机端直接与 AI 对话，相当于随身 AI 助手

### 13.3 定时任务使用技巧

#### 13.3.1 三种典型应用场景

**场景一：盘后自动复盘**

- Cron 表达式：`0 30 15 * * 1-5`（周一至周五 15:30）
- 分析模板：默认个股分析提示词
- Agent 模式：🧠 规划模式（plan_execute）
- 适用：每天收盘后自动分析持仓股，飞书推送结果

**场景二：盘前异动监控**

- Cron 表达式：`0 0 9 * * 1-5`（周一至周五 09:00）
- Agent 模式：⚡ 快速模式（react）
- 适用：开盘前 30 分钟扫描自选股竞价数据，发现异动及时推送

**场景三：周度策略回顾**

- Cron 表达式：`0 0 20 * * 5`（每周五 20:00）
- Agent 模式：🔬 DeepAgents（复杂多步分析）
- 适用：周末总结本周操作、分析下周机会

#### 13.3.2 Cron 表达式速查

| 表达式 | 含义 |
|--------|------|
| `0 * * * * *` | 每分钟 |
| `0 0 * * * *` | 每小时整点 |
| `0 30 9-15 * * 1-5` | 周一至周五 9:30-15:30 每小时 |
| `0 0 16 * * 1-5` | 周一至周五 16:00（收盘后） |
| `0 0 9 * * 1` | 每周一 9:00 |
| `0 0 0 1 * *` | 每月 1 号 0 点 |

> ⚠️ Cron 表达式为 6 段式（秒 分 时 日 月 周），首段为秒。

#### 13.3.3 模式选择建议

| 任务类型 | 推荐模式 | 原因 |
|----------|----------|------|
| 单只股票快速查询 | ⚡ 快速模式 | 单步工具调用，token 消耗低 |
| 多只股票综合分析 | 🧠 规划模式 | 先制定计划再分步执行 |
| 跨市场/跨品种复杂分析 | 🔬 DeepAgents | 内置子 Agent 委派，适合多步推理 |
| 不确定复杂度 | 🤖 自动选择 | 系统自动判断 |

#### 13.3.4 任务管理建议

- 创建任务后先点击「立即执行」一次，验证提示词和分析结果是否符合预期
- 长期不用的任务建议「暂停」而非「删除」，保留 Cron 配置便于复用
- 定时任务结果会推送到启用的通知渠道（本地/钉钉/飞书），不必开电脑也能收到飞书推送

### 13.4 AI 智能体使用技巧

#### 13.4.1 提示词模板设计

**系统提示词**（定义 AI 角色）示例：

```
你是一位资深 A 股分析师，擅长基本面 + 技术面综合分析。
分析时遵循以下原则：
1. 数据优先：先调取工具获取实时数据，再做判断
2. 多空对称：同时列出看多和看空的依据
3. 风险前置：在结论前明确风险点

```

**用户提示词**（支持 `{{stockName}}` 变量）示例：

```
请分析 {{stockName}} 的投资价值，包括：
1. 近 30 日 K 线技术形态
2. 最新财报关键指标
3. 主力资金近 5 日流向
4. 行业竞争格局
5. 给出 3 个关键观察价位
```

#### 13.4.2 记忆模式调优

浮动 AI 助手底部「记忆模式开关 + 条数」控制上下文保留轮数（1-10）：

| 场景 | 建议条数 |
|------|----------|
| 单只股票深度分析 | 1-2 条（节省 token） |
| 多股票横向对比 | 5-8 条（保留上下文） |
| 长对话策略讨论 | 10 条（完整对话历史） |

#### 13.4.3 工具调用与思考模式

- **工具调用开关**：开启后 AI 会主动调用 80+ 工具获取实时数据；关闭则纯文字回答（适合概念性问题）
- **思考模式开关**：开启后展示 AI 推理过程，便于理解分析逻辑；关闭则只输出结论

#### 13.4.4 多 AI 模型协作

go-stock 支持配置多个 AI 模型服务，建议：

- **DeepSeek 最新版**：⚡ 快速模式首选，响应快、性价比高
- **GLM 最新版**：🧠 规划模式首选，长文本分析能力强
- **Claude 最新版**：🔬 DeepAgents 首选，复杂推理能力强
- **本地 Ollama**：隐私敏感场景，数据不出本机

切换模型不会改变当前 Agent 模式（系统默认规划模式），可在底部独立切换。

#### 13.4.5 套餐接口配置

国内主流订阅制套餐接口（火山引擎 Ark Plan/Coding、腾讯云 lkeap plan 等）：

- 套餐接口需配套专属 API Key（通常 `sk-sp-` 开头），与按量付费 Key 不通用
- 配置后在 AI 模型服务中可直接选择对应接口地址
- 套餐计费更便宜，适合高频使用场景

### 13.5 K线分析技巧

#### 13.5.1 复权类型选择

| 分析目的 | 推荐复权 | 原因 |
|----------|----------|------|
| 技术形态分析 | 前复权 | 价格连续，支撑/压力位准确 |
| 长期收益计算 | 后复权 | 反映真实复权后收益 |
| 看真实成交价 | 不复权 | 显示原始价格 |
| 港股/中证指数 | 不复权 | 默认设置，主源 ExKLine2 不支持复权 |
| 场内 ETF | 不复权 | 默认隐藏切换按钮，避免误操作 |

> ⚠️ 切换复权时主源 ExKLine2 不支持会自动降级到东方财富源，可能略有延迟。

#### 13.5.2 测量画框实战

两点画矩形可快速计算：

- **涨跌幅百分比**：评估区间内表现
- **价格差**：测算目标价 / 止损价
- **K 线数量**：判断周期长度
- **成交量**：观察资金参与度

**典型用法**：

1. 在阶段性低点画框到当前价，观察上涨幅度和周期
2. 在震荡区间画框，判断突破方向
3. 多框对比不同时段表现（支持多框共存）

#### 13.5.3 波浪理论绘图

**5 浪模式（impulse5）**：

- 选 p0（浪 1 起点）和 p5（浪 5 终点）
- 系统自动绘制 5 浪结构 + 斐波那契回调位 + 通道线
- 适合完整波浪已走完后的复盘分析

**3 浪预测模式（predict3）**：

- 选 p0（浪 1 起点）和 p3（浪 3 当前位置）
- 系统绘制浪 1-2-3 实线（真实走势）+ 浪 4-5 虚线（预期投影）
- 适合当前处于浪 3 末端，预测浪 4-5 目标位

**拖拽重算**：

- 波浪任意点（端点或中间点）可拖拽调整
- 拖拽点自动 snap 到最近 K 线收盘价
- 适合根据实际走势微调波浪定位

#### 13.5.4 13 种绘图工具组合

| 工具 | 典型用途 |
|------|----------|
| 趋势线 | 判断上升趋势 / 下降趋势 |
| 射线 | 预测未来支撑 / 压力 |
| 水平线 / 垂直线 | 标记关键价位 / 时间窗口 |
| 十字线 | 标记关键转折点 |
| 斐波那契回撤 | 判断回调支撑位（38.2%/50%/61.8%） |
| 斐波那契扩展 | 判断上涨目标位（127.2%/161.8%） |
| 通道 | 判断价格通道上下轨 |
| 圆 | 时间周期分析 |
| 多头位置 / 空头位置 | 模拟交易盈亏 |
| 预测 | 投影未来价格区间 |
| 江恩扇 | 多角度时间价格分析 |

> 💡 测量 / 波浪 / 绘图工具互斥，激活一种会自动关闭其他，避免冲突。

### 13.8 交易日志使用技巧

#### 13.8.1 交易记录最佳实践

- **必填字段**：股票代码、方向、价格、数量、交易时间
- **建议填写**：交易原因、持仓心态（便于复盘心理偏差）
- **止损止盈价**：配合 K 线查看（需 VIP2）验证执行情况
- **手续费**：影响盈亏统计准确性，建议填写

#### 13.8.2 复盘分析流程

1. 筛选本月买入 / 卖出记录
2. 查看本月累计交易金额、盈亏统计
3. **当日盈亏 / 收益率**：基于实时持仓计算，红涨绿跌
4. 频繁交易提示：弹出警告但不阻止保存，便于自我觉察
5. 在 K 线图（VIP2）叠加成本线 / 止损线 / 止盈线，分析执行偏差

#### 13.8.3 心态记录价值

「持仓心态」字段看似冗余，实则是复盘的核心：

- 记录当时是「贪婪 / 恐惧 / 犹豫 / 决断」
- 复盘时统计不同心态下的胜率
- 识别自己的心理偏差模式（如"恐惧时卖飞"、"贪婪时追高"）
- 长期积累可形成个性化交易纪律

### 14.2 常见问题

#### Q: AI 分析不工作？

A: 检查以下几项：
1. 设置中是否已启用"AI诊股总开关"
2. 是否正确配置了 AI 模型的 API Key
3. 网络连接是否正常
4. 如使用代理，确认代理设置正确
5. 如使用套餐接口，确认 API Key 为 `sk-sp-` 开头的专属 Key

#### Q: 数据不更新？

A: 尝试以下方法：
1. 检查网络连接
2. 确认当前是否为交易时间（休市期间部分数据不会刷新）
3. 重启软件
4. 在设置中启用"启动时更新基础信息"

#### Q: 如何添加自选股？

A: 在股票自选页面右下角的搜索栏中输入股票名称或代码（含场内ETF），选中后点击"关注"按钮。在K线图组件中也可通过工具栏的关注按钮快速关注。

#### Q: VIP 功能无法使用？

A: 确认以下几项：
1. 赞助码是否正确输入
2. 点击"验证"按钮确认赞助码有效
3. 重启软件使 VIP 状态生效

#### Q: 如何收到股票预警通知？

A: 需要完成以下配置：
1. 在成本设置中设置涨跌提醒百分比或股价提醒
2. 在设置中开启"本地推送"或配置"钉钉推送"或"飞书应用机器人"
3. 确保在交易时间内运行软件

#### Q: AI 智能体菜单不显示？

A: AI 智能体菜单需要在后台配置中启用对应功能后才会显示。

#### Q: 多周期K线 / K线分析 / 浮动AI助手提示权限不足？

A: 这三个功能均需要 VIP2 及以上等级。请在关于页面查看当前 VIP 等级，并在设置中输入赞助码升级。

#### Q: 港股 K 线数据错误（显示成A股数据）？

A: 已修复。港美股 K 线统一走 MAC Ex 扩展行情（ExKLine2 + 主板=31/创业板=48/美股=74），东方财富为降级源。如仍异常请升级到最新版本。

#### Q: 提示词广场/问答广场无法访问？

A: 请检查设置中的"提示词广场地址"是否正确，默认为 http://go-stock.sparkmemory.top:1918/api。如网络受限可尝试修改为其他可用地址。

#### Q: 问财功能不可用？

A: 问财功能需要配置"问财API密钥"。如返回 401 错误，多为每日配额耗尽（次日 0 点重置）。请在设置中填写同花顺问财开放平台的 API Key。

#### Q: 飞书机器人回复内容被截断？

A: 飞书机器人对长文本（>500字）、含代码块、含表格分隔行或超过 20KB 的内容自动转图片回复，图片回复失败时会降级为卡片回复。

#### Q: 「只提醒红字或关注个股的新闻」开启后没收到通知？

A: 该开关默认关闭。开启后仅推送红色重磅消息或内容包含非空名称关注股票的资讯，会过滤掉大量普通资讯。如需收到所有资讯，请关闭该开关。

#### Q: 交易日志提示频繁交易？

A: 系统检测到频繁交易时会弹出警告提示，但不会阻止保存，您可以继续记录交易。

#### Q: 升级后自选股和分组会丢失吗？

A: Windows 卸载逻辑已优化，会保留用户数据。升级版本时直接覆盖安装即可，自选股、分组、概念、交易日志等数据均保留。

### 15.1 技术栈

### 15.2 AI Agent 架构

基于 cloudwego eino 框架构建。提供三种 Agent 实现：

- **React Agent**：简单查询模式，单步工具调用，包含错误恢复和未知工具处理中间件，以及智能内容压缩（优先级：标题 > 摘要 > 数据 > 其他）。已修复 `close(ch)` 与 `processMessageFuture` 协程竞态导致最终结果不显示的 bug。
- **PlanExecute Agent**：复杂分析模式，Planner→Executor→Replanner 管道，最大7次迭代，分级压缩执行结果。**系统默认模式**。
- **DeepAgents**：内置任务规划与子 Agent 委派，适合复杂多步分析。

### 15.4 MCP 与技能扩展

**MCP（Model Context Protocol）**：在研究中心添加 MCP 服务器配置后，AI 智能体运行时自动通过 `getMCPTools()` 动态加载外部工具。

**技能系统**：通过技能管理器创建自定义技能，配置触发关键词和绑定MCP服务。AI 智能体运行时通过 `buildSkillPrompt()` 检测提问内容是否匹配技能触发关键词，匹配则注入技能系统提示词。技能分类包括：股票分析、技术分析、基本面分析、量化策略、风险管理、资讯研究、通用。

### 15.5 错误上报

前端内置 `window.onerror` 处理器，会将 JavaScript 错误信息（页面、消息、来源、行号、列号、堆栈）自动发送给后端 EventsEmit，便于问题排查。

### 15.6 关键技术约定

- K线复权：A股默认前复权，港股/中证指数/场内ETF默认不复权
- 复权切换仅对日K/周K/月K/季K/年K有效，分时周期不显示切换按钮
- ExKLine2 源不支持复权，切换复权时自动降级到东方财富源
- 关注股票名称为空时自动过滤新闻推送，避免 `strings.Contains(s, "")==true` 导致过滤器失效
- 「全部」标签页表格分组列：`codeToGroupNames` 存对象数组（render 用 name 显示 NTag、onClick 用 id 调 updateTab 跳转页签、sorter 用 name 拼接），`codeToGroupIds` 存 number[] 供筛选
- 概念标签与分组系统独立共存，不产生页签
- naive-ui NDropdown 的 `menu-props`（JS `menuProps`）prop 类型是函数 `(option, options) => HTMLAttributes`，不是对象，传对象会导致下拉菜单打不开
