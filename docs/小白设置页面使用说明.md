# go-stock 设置页面使用说明（零基础）

> 本文依据当前程序的设置页面与后端保存逻辑编写，适合第一次配置 go-stock 的用户。
>
> **最重要的一句话：** 改完设置后，请点击页面底部的 **保存设置**；AI 模型则需要在独立的 **AI模型服务** 页面点击 **保存配置**。

## 1. 设置页在哪里

在窗口底部主导航中打开 **设置 → 基础设置**。页面包含以下区域：

1. **基础设置**：软件外观、更新、数据和部分数据服务密钥。
2. **通知设置**：电脑、钉钉、飞书的通知方式。
3. **飞书应用机器人（AI 对话）**：让飞书中的机器人接收消息并由 AI 回复。
4. **AI 设置**：AI 诊股开关、采集超时、提示词和爬虫代理。
5. **AI模型服务**：独立页面，用于添加 AI 平台、API Key 和模型。

对刚开始使用的用户，建议只完成“基础设置”和“AI模型服务”；通知、飞书机器人、代理和高级提示词可在熟悉软件后再开启。

## 2. 开始前的安全原则

下列内容都是敏感凭证，请只填写自己从官方平台获得的值：

- AI 平台 API Key；
- 问财 API Key；
- 东方财富 AI Key；
- 钉钉、飞书 Webhook；
- 飞书 App Secret；
- 代理地址中包含的账号或密码。

不要把它们发送到群聊、截图、Issue、客服对话或代码仓库。**导出配置会导出当前设置和 AI 模型配置，其中可能包含以上密钥。** 导出的 JSON 文件应视为密码文件，只能加密保存或在自己的设备之间传输。

## 3. 推荐的首次配置顺序

1. 打开 **设置 → 基础设置**，保留大部分默认值。
2. 在 **AI 设置** 打开“AI诊股”。
3. 点击“前往管理”，进入 **AI模型服务**。
4. 添加并保存一条“文本对话”模型配置。
5. 返回基础设置，点击 **保存设置**。
6. 到 AI 智能体或浮动 AI 助手中选择该模型，先发一个简单问题测试。

如果你只想看行情和维护自选股，可跳过第 2 至第 6 步。

## 4. 基础设置

### 4.1 启动时更新基础信息

**作用：** 每次启动软件时，更新股票基础数据，例如股票名称、代码和场内 ETF 相关基础信息。

**建议：** 新用户开启。网络不稳定、启动速度优先时可以关闭，之后再按需手动更新或重新开启。

### 4.2 数据刷新间隔

**作用：** 控制行情相关页面的刷新频率，单位为秒。

**建议：** 保持默认值 `1`。数值越小，刷新越频繁，也会增加网络请求和电脑负担；网络较慢时可以适当调大。

### 4.3 暗黑主题

**作用：** 切换深色或浅色界面。

**建议：** 完全按个人习惯选择，不影响行情、AI 或数据准确性。

### 4.4 更新通道

| 选项 | 含义 | 小白建议 |
| --- | --- | --- |
| `Release（稳定版）` | 只接收正式发布版本 | **推荐** |
| `Pre-release（预发布版）` | 可提前体验待发布功能 | 能接受偶发问题时再选 |
| `Dev（开发版）` | 更早获取开发中的版本 | 不建议日常使用 |

选择后要点击 **保存设置** 才会生效。

### 4.5 浏览器安装路径

**作用：** 新闻、网页信息采集等功能会使用本机浏览器。程序会尝试自动识别浏览器路径。

**建议：** 能正常使用资讯功能时保持为空；只有采集功能提示找不到浏览器时，再填入浏览器可执行文件的完整路径，例如 Windows 的 `msedge.exe` 或 `chrome.exe` 所在位置。

不要填写网页地址，也不要填写浏览器快捷方式文件。

### 4.6 指数基金

**作用：** 控制“基金自选”功能入口是否显示。

**建议：** 想跟踪场内 ETF 时开启；暂时不用基金时关闭，导航会更简洁。

### 4.7 东财唯一标识（qgqp_b_id）

**作用：** 为部分东方财富相关的数据请求提供浏览器 Cookie 中的唯一标识。

**何时填写：** 只有相关数据功能提示需要该标识或无法获取数据时再填。普通新用户可以先留空。

**获取方式：**

1. 使用浏览器访问东方财富网站并登录自己的账号。
2. 按 `F12` 打开开发者工具，进入“网络（Network）”。
3. 打开任意请求，在请求 Cookie 中找到 `qgqp_b_id`。
4. 只复制等号后的值，粘贴到软件中并保存。

Cookie 可能关联登录状态，不要对外分享；失效后需要重新获取。

### 4.8 问财 API 密钥

**作用：** 启用同花顺问财相关能力，例如智能选股、行情查询和研报搜索。

**何时填写：** 需要使用问财功能时填写；不用可留空。

**操作：** 在同花顺问财开放平台创建或获取 API Key，填入后点击 **保存设置**。如果遇到权限、余额或配额错误，应到问财平台核实，而不是反复更换密钥。

### 4.9 东财 AI 密钥

**作用：** 用于东方财富妙想 AI 的个股业绩点评功能。

**何时填写：** 仅在需要该项功能时填写。

**操作：** 从东方财富妙想 AI 平台获取 API Key，填入后保存。该密钥与通用大模型的 API Key 不是同一个东西。

### 4.10 赞助码

**作用：** 用于验证并激活相应 VIP 功能。

**操作：**

1. 输入获得的赞助码。
2. 点击 **立即验证** 查看结果。
3. 确认无误后，再点击 **保存设置**。

例如，**K线分析**需要 VIP2 或以上有效权益。验证失败时，不要把完整赞助码发到公开渠道。

### 4.11 提示词广场地址

此输入框是只读的，显示软件内置的社区服务地址 `https://go-stock.sparkmemory.top/api`。

**不能修改。** 若提示词广场、问答广场或技能广场无法访问，请检查网络连接后稍后重试，不要尝试通过修改这个地址排查。

## 5. 通知设置

通知默认不是必需功能。建议先只启用“本地推送”，等确认软件工作正常后再配置钉钉或飞书。

### 5.1 钉钉推送

**用途：** 将通知发送到钉钉自定义机器人。

1. 打开“钉钉推送”。
2. 填入钉钉机器人 Webhook 地址。
3. 点击 **发送测试通知**。
4. 在钉钉群确认是否收到测试消息。
5. 点击 **保存设置**。

测试失败时，检查 Webhook 是否完整、机器人是否仍在群内，以及钉钉机器人的安全设置是否允许当前请求。

### 5.2 飞书推送（自定义机器人）

**用途：** 把软件通知推送至飞书自定义机器人。它只负责发送通知，和后面的“飞书应用机器人 AI 对话”是两项独立功能。

1. 打开“飞书推送”。
2. 填写飞书自定义机器人的 Webhook 地址。
3. 若该机器人启用了签名校验，再填写签名校验 Secret；没有启用则留空。
4. 点击 **发送测试通知**。
5. 确认飞书群收到消息后保存。

### 5.3 本地推送

**用途：** 在当前电脑显示系统通知。

**建议：** 希望接收预警时开启。若没有看到通知，还要检查 Windows 或 macOS 是否禁止 go-stock 显示系统通知。

### 5.4 弹幕功能

**用途：** 显示和使用项目社区的弹幕互动功能。

**建议：** 与股票分析无关，按兴趣开启；不想被弹幕干扰时关闭。

### 5.5 显示滚动快讯

**用途：** 在界面中显示滚动市场快讯。

**建议：** 希望随时浏览摘要信息时开启；需要专注看图或电脑性能较低时关闭。

### 5.6 市场资讯提醒

**用途：** 为市场资讯生成通知。

开启后会出现“只提醒红字或关注个股的新闻”：

| 选项 | 建议场景 |
| --- | --- |
| 关闭 | 想接收较完整资讯流，可能较频繁 |
| 开启 | **推荐新手开启**；仅保留红色重点资讯或与自选股有关的资讯，减少干扰 |

## 6. 飞书应用机器人（AI 对话）

这一部分让你在飞书中与 go-stock 的 AI 对话。它不同于“飞书推送”：前者用于接收用户消息并 AI 回复，后者只发送通知。

如果你还没有创建飞书企业自建应用，请暂时跳过本节。

### 6.1 配置前提

在飞书开放平台完成以下准备：

1. 创建企业自建应用，获得 `App ID` 与 `App Secret`。
2. 启用机器人能力。
3. 添加事件订阅 `im.message.receive_v1`。
4. 选择**使用长连接接收事件**，不需要部署公网回调地址。
5. 配置消息相关权限，并发布/审核应用。
6. 先在 **AI模型服务** 创建一个可用的文本对话模型。

### 6.2 页面字段怎么填

| 字段 | 填写/选择方式 | 新手建议 |
| --- | --- | --- |
| 启用飞书应用机器人 | 打开开关 | 确认前提完成后再开 |
| App ID / App Secret | 填飞书开放平台中的值 | 不要外泄 |
| AI 配置 | 选择已保存的文本对话模型 | 选择自己已测试成功的模型 |
| 系统提示词 | 可选；选择已保存模板 | 初次使用选默认 |
| Agent 模式 | 快速、规划、深度、直接或自动 | 先用“自动”或“快速模式” |
| 启用工具调用 | 允许 Agent 调行情、资讯等工具 | 希望做股票分析时开启 |
| 深度思考 | 让支持推理的模型输出思考过程 | 仅推理模型开启 |
| 多轮记忆 | 携带最近一轮上下文 | 新手先关闭，避免群聊上下文混杂 |

填写后依次点击 **保存设置 → 启动机器人 → 查询状态**。状态显示“运行中”后，再到飞书中测试私聊机器人；群聊一般需要 `@机器人` 才会回复。

## 7. AI 设置

### 7.1 AI诊股

**作用：** 控制 AI 诊股相关能力是否启用。

**建议：** 已配置至少一个模型后开启；暂时没有 API Key 时可以先关闭。首次运行时，程序默认将此项设为开启。

### 7.2 Crawler Timeout（秒）

**作用：** 限制资讯网页采集等操作最长等待时间。

**建议：** 保持默认或设置为 `30` 秒以上。网络很慢时可以适度增加；设置过高会让失败请求等待更久。

### 7.3 日 K 线数据（天）

**作用：** AI 诊股时使用的日 K 线历史天数。

**可设置范围：** 30 到 60 天。

**建议：** 从 `30` 天开始。天数越多，输入给模型的数据越多，速度更慢、Token 消耗也更多。

### 7.4 爬虫 HTTP 代理

**作用：** 仅为资讯/网页采集等爬虫请求设置 HTTP 代理。

**建议：** 普通用户保持关闭。需要时打开开关并填写代理地址；AI 模型服务的代理在“AI模型服务”中单独设置，两者不是同一项。

### 7.5 默认系统提示词

**作用：** 设定 AI 的角色、写作风格和输出规则。

**建议：** 初学阶段留空或使用简短、明确的限制，例如：

```text
请以股票研究助理的身份回答。区分已知事实、推测和风险，不提供确定性买卖指令。
```

避免在提示词中粘贴 API Key、账户信息或个人隐私。

### 7.6 默认个股分析提示词

**作用：** 作为个股分析的默认问题模板。

**可用变量：** `{{stockName}}` 和 `{{stockCode}}`。发送时软件会把变量替换为实际股票名称和代码。

新手可使用：

```text
请分析 {{stockName}}（{{stockCode}}）近期价格表现、资金流向、公告和风险。
请区分事实与推测，不提供买卖指令。
```

### 7.7 保存、导出与导入

| 操作 | 实际行为 | 注意事项 |
| --- | --- | --- |
| 保存设置 | 保存基础、通知、飞书和 AI 设置 | 不会覆盖独立页面中的 AI 模型配置 |
| 导出配置 | 导出当前设置及 AI 模型配置为 JSON | **可能含 API Key、Webhook 和 Secret** |
| 导入配置 | 读取 JSON，恢复页面设置；其中的 AI 模型配置会单独写入 | 只导入自己信任且确认来源的文件 |

导入完成后，仍应点击 **保存设置**，并进入 **AI模型服务** 核对模型、接口和密钥是否符合预期。

## 8. AI模型服务：添加第一个对话模型

点击 **设置 → AI模型服务**，或在 AI 设置卡片中点击 **前往管理**。

### 8.1 添加步骤

1. 点击 **添加AI配置**。
2. 填写“配置名称”，例如“日常分析模型”。
3. 选择或填写“接口地址”。
4. 填写该平台官方生成的“令牌（apiKey）”。
5. 选择“模型类型”为 **文本对话**。
6. 点击模型名称输入框获取模型列表，或按服务商文档手动输入模型名。
7. 点击抽屉中的 **确定**。
8. 回到列表，点击右上角 **保存配置**。

没有点击“保存配置”时，新建或编辑内容只在当前页面暂存，重开页面后不会保留。

### 8.2 常用字段说明

| 字段 | 含义 | 小白建议 |
| --- | --- | --- |
| 配置名称 | 仅用于软件中识别 | 写成“平台-模型-用途” |
| 接口地址 | 模型服务 API 地址 | 仅用平台官方文档中的地址 |
| 令牌（apiKey） | 调用模型的凭证 | 保密；不要填写登录密码 |
| 模型类型 | 文本对话或向量模型 | 日常 AI 问答选“文本对话” |
| 模型名称 | 服务商提供的模型 ID | 可尝试获取模型列表 |
| Temperature | 控制输出随机性 | 保持默认；分析任务不建议调得过高 |
| MaxTokens | 单次最多生成的输出量 | 保持自动/默认，过小会截断回答 |
| 上下文窗口 | 输入和输出可使用的总容量 | 初学者保持 `0`，由软件自动推导 |
| Timeout（秒） | 单次模型请求最长等待时间 | 不低于 60 秒 |
| 深度思考 | 启用推理模型的思考能力 | 只给明确支持推理的模型开启 |
| 视觉理解 | 允许向模型发送图片 | 只给支持图片的模型开启 |

### 8.3 文本对话与向量模型的区别

| 类型 | 用在哪里 | 是否是首次必配 |
| --- | --- | --- |
| 文本对话 | AI 智能体、浮动 AI 助手、飞书机器人 | **是** |
| 向量模型 | 知识库检索、长期记忆 | 否；用到知识库时再配 |

不要把聊天模型误设为向量模型，也不要把向量模型作为日常对话模型。

### 8.4 视觉理解与深度思考

- **视觉理解：** 仅当模型确实支持图片输入时才开启。对普通文本模型强行开启，发送图片时可能报“模型不支持图片”。
- **深度思考：** 仅当模型支持推理时开启。普通模型开启后不一定有收益，反而可能导致兼容性或输出预期问题。

### 8.5 HTTP 代理与自定义 Header

这两项是给特殊网络环境、企业网关或代理服务使用的高级功能：

- 模型代理只作用于此 AI 配置，不等同于“AI 设置”中的爬虫代理；
- 自定义 Header 用于服务商要求额外请求头时配置；
- `Authorization` 由软件根据 API Key 自动处理，通常不要自行添加；
- `{{sessionId}}` 与 `{{uuid}}` 是高级网关的模板变量。

不清楚用途时请保持关闭和留空。

## 9. 两种常见配置方案

### 方案 A：只看行情

适合暂时没有 AI API Key 的用户：

- 启动时更新基础信息：开启；
- 数据刷新间隔：默认；
- 更新通道：Release；
- 本地推送：按需开启；
- AI诊股：关闭或保持默认但不配置模型；
- 其余密钥、飞书、钉钉、代理：留空/关闭。

### 方案 B：日常 AI 分析

适合已有一个大模型 API Key 的用户：

- 基础设置：保持默认；
- AI诊股：开启；
- 日 K 线数据：30 天；
- 爬虫代理：关闭；
- AI模型服务：添加 1 条文本对话模型，先关闭深度思考和视觉理解；
- 本地推送：开启；
- 默认个股分析提示词：使用第 7.6 节的示例；
- 飞书、钉钉、向量模型：熟悉后再配置。

## 10. 配置后如何验证

1. 点击基础设置页的 **保存设置**，应出现“保存成功！”。
2. 在 **AI模型服务** 确认模型列表中有你的配置，并已点击 **保存配置**。
3. 打开 **AI智能体** 或右侧浮动 AI 助手，选择模型。
4. 发送一条简单问题，例如：

```text
请用三句话解释股票的成交量、涨跌幅和市盈率分别是什么。
```

5. 若能正常回复，说明模型连接可用；再按需开启深度思考、图片理解、飞书或通知。

## 11. 常见问题

### 保存了 AI 模型，但基础设置页没有显示？

AI 模型由独立的“AI模型服务”页面管理。回到基础设置只会显示配置数量；请在独立页面检查并点击 **保存配置**。

### 为什么修改了 AI 模型后还是旧效果？

确认是否点击了“保存配置”。基础设置页的“保存设置”不会替代 AI模型服务页的保存操作。

### 为什么导入配置后仍要检查密钥？

导入会恢复 JSON 中的内容，包括可能过期、失效或不属于当前机器的密钥和 Webhook。导入后应逐项检查，并用测试通知或一条简单 AI 问题验证。

### AI 请求失败怎么办？

按顺序检查：接口地址、API Key、模型名称、余额/额度、网络或代理设置。优先使用服务商官方文档中的地址和模型 ID，不要从不可信教程复制密钥或网关地址。

### 我能在这里配置长期记忆或用户画像使用哪个模型吗？

不能。长期记忆和用户画像的模型绑定分别在 **知识库管理** 和 **我的画像** 的专用页面配置；基础设置保存不会覆盖这些专用绑定。
