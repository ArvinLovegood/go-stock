## 一、行情与数据源

### 1.1 首页板块/概念资金流向图（2026.11.24 - 2026.11.25）

首页「大盘分析」下方新增**板块资金流向**与**概念资金流向**并排对比图，无需进入市场行情页即可观察当日资金主线。

**入口**：首页 → 「资金流向 · 板块 / 概念 多板块对比」折叠栏。

**核心能力**：

- **可折叠**：点击标题栏展开/收起，状态写入 `localStorage`，重启后保持；
- **默认最近交易日**：当天为周末或节假日时自动回退到最近一个交易日，不会显示空图；
- **自动刷新**：仅 A 股交易时间内每分钟刷新，收盘后停止请求；
- **排名视图（默认）**：发散条形图展示净流入 Top10 与净流出 Top10，红色为流入、绿色为流出，解决几十条折线挤在一起看不清的问题；
- **趋势视图**：多板块/概念日内净流入折线对比，点击条形或折线可聚焦单个标的，聚焦标签可一键关闭；
- **播放回放**（趋势视图）：播放 / 暂停 / 重播，进度滑块，0.5x / 1x / 2x / 4x / 8x 倍速；
- **日期切换**：可回看历史交易日；
- **添加对比标的**：板块/概念下拉搜索，追加到当前图表（已展示的自动排除）；
- **成分股下钻**：点击板块/概念名称打开成分股列表（按主力净流入 / 涨跌幅 / 成交额排序）。

> 首页使用 `compact` 紧凑模式：只保留图表与日期/刷新/排名/趋势切换，隐藏播放栏和底部 Top20 表格；完整版在市场行情 → 板块资金流向 / 概念资金流向。

### 1.2 自选股股东户数与筹码集中度（2026.11.23）

自选卡片与「全部」列表新增 A 股股东数据，用于辅助判断筹码集中/分散趋势。

**展示字段**：

| 字段 | 说明 |
|------|------|
| 股东户数 | 最新一期报告期股东总户数，如 `85,000 户` |
| 环比 | 相对上一期变化百分比，**增加显红（趋于分散）、减少显绿（趋于集中）** |
| 筹码集中度 | 接口返回的集中度描述（如「非常集中」「较集中」），并标注报告期 |
| 报告期 | 形如 `2026-09-30`，表格与卡片均显示完整日期 |

**使用说明**：

- 仅 A 股（`sh` / `sz` / `bj` 前缀）展示，港股、美股显示 `—`；
- 股东户数为季度级低频数据，前端按**自然月缓存**到 `localStorage`，跨月自动失效重拉；历史月份缓存会自动清理；
- 首次加载按每批 8 只限流拉取，避免瞬时打满数据源；
- 表格「股东户数」列支持排序，首次打开若尚未返回显示 `—`，稍后自动填充。

## 二、K 线与买卖点

### 2.1 15 路指标组合体系（2026.11.16）

买卖点从固定权重打分重构为 **路由注册表 + 组合模式**，全部等权计分、分组门控，K 线箭头、全市场扫描、后台监控与 OKX 自动交易同口径。

| 组 | 路由 | 买点 | 卖点 |
|----|------|------|------|
| 震荡组 | RSI(14) | 上穿 30 | 下穿 70 |
| 震荡组 | KDJ(9) | 低位金叉 | 高位死叉 |
| 震荡组 | CCI(20) | 回穿 -100 | 回穿 +100 |
| 动量组 | MACD(12,26,9) | 金叉 | 死叉 |
| 动量组 | TEMA(21,5) | 斜率转正 | 斜率转负 |
| 动量组 | TRIX(15) | 斜率转正 | 斜率转负 |
| 动量组 | ADX(14) | 转强（DI+>DI-） | 转弱 |
| 量价组 | VWAP | 收复 | 跌破 |
| 量价组 | 成交量 | 放量 | 放量 |
| 量价组 | MFI(14) | 上穿 20 | 下穿 80 |
| 量价组 | CMF(20) | 转正 | 转负 |
| 趋势组 | Donchian(20) | 突破 20 期高 | 跌破 20 期低 |
| 趋势组 | Supertrend(10,3) | 趋势翻多 | 趋势翻空 |
| 趋势组 | BBI(3,6,12,24) | 上穿 | 下穿 |
| 摆动区组 | SMI 区域 | 底部区转强 | 顶部区转弱 |

**指标组合模式**（信号监控面板 →「检测参数」）：

| 模式 | 触发条件 | 适用场景 |
|------|----------|----------|
| `score`（默认） | 共振分数达标（命中路数 + 覆盖组数满足灵敏度档位） | 沿用共振语义 |
| `any` | 选中路由中任一路命中即出信号 | 只做单一信号，如只做 MACD 金叉 |
| `all` | 滚动窗口内全部选中路由齐备才出信号 | 多条件同时满足的严格入场 |

- 股票监控 / OKX 模拟盘 / OKX 实盘三实例**独立配置**路由与模式；
- 配置纳入基线指纹，修改配置不会吞掉已武装、尚未触发的信号；
- 日 K 类周期启用 4 路扩展维度后满分 15 → 19，命中门限等比放大，灵敏/标准/严格档位语义不变。

### 2.2 SMI 底部/顶部区域信号（2026.11.16 - 2026.11.18）

- 主图按滚动 300 根 SMI 的 P20/P80 分位自适应计算底部/顶部阈值，纯历史数据驱动、无未来函数；
- SMI 进入底部区域绘制**绿色竖带**，进入顶部区域绘制**红色竖带**；
- 区域结束 + SMI 上穿/下穿 Signal 线**双确认**后标出 B/S 预测买卖点，10 根内未确认自动作废；
- 作为买卖点第 15 路「SMI 底部区转强 / 顶部区转弱」并入共振体系，可在 OKX 自动交易指标组合中勾选 `smiZone`。

### 2.3 四种反转信号（2026.11.15）

| 信号 | 预警条件 | 确认条件 |
|------|----------|----------|
| 假突破反转 | 跌破前 20 根低点或突破前 20 根高点 | 10 根内收盘收回；突破预警 K 线极值或超时失效 |
| RSI 摆动 | RSI 在超卖/超买区摆动反转 | 详见指标提示（悬停指标名查看完整口径） |
| 衰竭量反转 | 下跌后放量（> 前 20 根均量 × 1.8）出现长下影或看涨吞没 | 10 根内收盘突破预警 K 线最高价；跌破最低价或超时失效 |
| 双底/双顶 | 两个拐点间隔 4~40 根、价差 ≤ 3% | 10 根内收盘突破颈线；跌破双底（双顶反向）或超时失效 |

标注为「预警（预）→ 确认（确）→ 失效（失）」三态，红色看涨、绿色看跌、灰色失效。

### 2.4 扩展 4 路指标（2026.11.14）

- **BIAS 乖离率**（6/12/24 三线）；
- **K 线形态识别**：启明星 / 黄昏星 / 红三兵 / 三只乌鸦 / 吞没 / 锤头 / 上吊线 / 流星 / 倒锤头，共 9 种；
- **获利盘比例**：筹码分布换手衰减模型，实时曲线；
- **多周期共振**：日线因子聚合到周线评分，防未来函数；
- 4 路接入共振打分：BIAS 与 K 线形态计入震荡组、获利盘计入量价组、多周期共振计入趋势组；仅日 K 类周期启用，数据缺失自动降级。

### 2.5 测量画框内置 Volume Profile（2026.11.25）

K 线工具栏「测量」画框新增框内成交量分布，画框即可看区间筹码结构：

- **框内 VPVR 直方图**：贴近测量框右缘向左展开，按价格档统计区间成交量；
- **买卖量拆分**：红色为主动买量、绿色为主动卖量，柱内拼接展示；
- **POC 虚线**：品红色虚线标出成交量最大价格，框右缘显示 POC 价格小标签；
- **Value Area**：青色虚线标出 VA 上沿（VAH）与下沿（VAL），VA 外档位降低透明度；
- 测量框仍显示涨跌幅、价差、K 线数、成交量，并按涨/跌使用不同框内配色；
- 支持多框绘制，ESC 清空当前预览，Ctrl+Z 撤销最近一框。

> 与全图 VPVR 指标的区别：全图 VPVR 为琥珀色、按可视区间计算；测量框 VPVR 为品红 POC、只统计框内时间与价格区间，两者可同时开启对照。

### 2.6 搜索与图表体验（2026.10 - 2026.11）

## 三、信号监控与自动交易

### 3.1 全市场信号扫描（2026.10.27，2026.11.08 增强）

- 信号监控面板新增「全市场信号扫描」页签，按买卖点共振对全市场 A 股批量扫描；
- 支持市场范围、板块细分（主板/创业板/科创板/北交所，多选）过滤；
- 自动剔除 ETF、债券等非个股标的；
- 结果携带板块/概念信息，可按行业、概念关键词即时过滤；
- 扫描进度实时推送，可中途停止，面板关闭后 Go 侧继续执行。

### 3.2 MASS 反转预警扫描（2026.11.08）

扫描「MI 凸起已形成、尚未回落确认」且处于多头/上升趋势的标的：

- 支持日 K / 60 分 / 30 分 / 15 分 / 5 分 / 1 分 / 周 K 多周期；
- 趋势证据 5 路自选（多头排列 / MA20 上行 / Supertrend 翻多 / ADX 强多头 / 通道上半区），按满足个数过滤；
- 支持「进入预警根数」筛选（刚进入 1~3 / 4~7 / 8~15 / 15 以上），计数单位跟随周期；
- 结果按趋势分、MI 超线幅度排序，支持 K 线复核与 Excel 导出；
- 另有「MASS 策略回测」（入口默认隐藏）：凸起首日收盘入场，9 种卖出策略并行，按趋势分分桶统计。

### 3.3 OKX 信号自动交易（2026.10）

- 支持 OKX **模拟盘 / 实盘**，两套实例独立配置、独立监控池；
- 开仓可附带交易所侧 TPSL 止盈止损条件单，并自动清理孤儿单；
- 下单四道闸：方向模式、大势门控、单日限笔数、开单最低止盈收益率；
- 交易金额支持**名义价值口径**；支持持仓止盈止损监控与止损退避冻结；
- 满仓时自动换仓腾槽；反手开仓设最低分数门槛；
- 新增 Mass Index 反转闸门，K 线主图反转窗口阈值分位自适应；
- 信号监控支持 MA144 趋势过滤、OKX 池 15 分钟周期；
- K 线图可标注买卖点 / 止盈止损价位；
- OKX 交易面板支持红涨绿跌 / 绿涨红跌习惯切换，模拟盘/实盘共用并本地记忆。

> 参数逐项说明见 [OKX自动交易设置参数详解](./OKX自动交易设置参数详解.md)。

### 3.4 永续趋势扫描与自动调池（2026.10.25）

- 「趋势扫描」对全市场永续合约做 5 路趋势证据评分，结果可一键加入监控池；
- 「趋势跟随」自动调池：5 入 3 出滞回，按趋势分替换池内标的；暂留池中标的不会立即平仓；
- 自动调池有独立总闸，模拟盘/实盘配置各自持久化；
- 面板显示上次运行摘要。

### 3.5 信号面板体验（2026.11）

- 信号流水、全市场扫描、信号监控结果新增「板块/概念」列，支持行业/概念即时过滤；
- 轻量 K 线图支持快捷切换大盘指数（上证/深成/创业板指等），宿主页面标题同步；
- 信号时间统一按触发墙钟时间展示；
- 信号流水筛选默认「今天」，跨天常驻后自动滚动到当前自然日，支持一键重置；
- AI 推荐列表保存最近 8 轮扫描快照，可回看历史轮次；
- AI 助手与信号监控边缘触发条支持拖拽：脱离边缘变 48px 圆球，靠近左右边缘 ≤28px 自动吸附，位置本地记忆。

## 四、AI Agent 与工具

### 4.1 常驻选股工具（2026.11.25）

以下 5 个选股工具已登记进跨领域常驻白名单，**任何问题（包括模糊问法）都对模型可见**，不再依赖关键词命中：

| 工具 | 作用 |
|------|------|
| `SearchStockByIndicators` | 自然语言问句选股（东财 AI 选股，问财回退） |
| `FilterStocks` | 结构化技术指标 / 人气 / 连涨连跌筛选 |
| `SearchBk` | 板块 / 概念 / 指数问句查询 |
| `SearchETF` | ETF 问句查询 |
| `HotStrategyTable` | 当前热门选股策略排行榜 |

使用前需在设置页配置「东财唯一标识（QgqpBId）」；`SearchStockByIndicators` 可选配问财 API Key 作为 503 回退。详细参数与示例见 [Agent常驻选股工具使用说明](./Agent常驻选股工具使用说明.md)。

### 4.2 会话管理与导出（2026.10）

- AI 助手支持多会话管理与会话搜索；
- 会话支持重命名与置顶；
- 支持导出会话为 Markdown 文件；
- 新增系统桌面通知方法，长任务完成后可提醒。

### 4.3 联网搜索与网页抓取（2026.10.21）

- 集成 DeepSeek 联网搜索 / 网页抓取 API，AI 助手可获取实时网络信息；
- 需在设置中配置 DeepSeek 搜索密钥；
- 搜索结果不能用于历史时点回测。

### 4.4 工具扩展（2026.10 - 2026.11）

- 币安 USDT-M 永续合约工具接入 Agent，新增加密分组；
- OKX 交易客户端与工具实现，交易所快讯面板；
- Yahoo Finance 个股新闻搜索；
- 彭博市场新闻检索；
- 通达信异动监控与设置项接入。

### 4.5 输出稳定性（2026.10 - 2026.11）

- AI 总结支持手动中断，底层取消大模型调用；
- 输出被 `max_tokens` 截断时自动续写（最多 3 次），仍不完整则提示调大最大输出 Tokens；
- 兼容 OpenAI 兼容网关把工具调用结束标记错发成 `finish_reason=stop`；
- 流提前断开时文末追加「输出流提前中断」提示；
- React 模式思考区/回答区分离：工具轮评论进思考区、终轮回答进正文区；
- DeepAgents 模式新增自动升级规则，识别深度研究、多步任务与报告产出类问题。

## 六、升级与兼容说明

1. **15 路买卖点**：默认参数会自动迁移，原 14 路配置继续可用；如需使用 `any` / `all` 组合模式，请在信号监控面板重新选择指标路由；
2. **股东户数**：首次加载会按月度缓存逐批拉取，自选数量较多时请等待片刻；跨月后自动重新拉取；
3. **首页资金流向图**：默认展开，如觉占用空间可点击标题折叠，状态会记忆；
4. **Yahoo / Bloomberg / DeepSeek 搜索**：均依赖海外网络，使用前请在设置中配置海外代理或搜索密钥；
5. **合约行情**：需在设置中开启 `enableContracts`；定制版构建默认隐藏；
6. **AI 常驻选股**：需配置东财唯一标识 `QgqpBId`，否则工具可见但执行会返回提示。
