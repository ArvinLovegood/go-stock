# go-stock 小白入门使用手册

> 适合第一次使用股票软件、AI 工具或 go-stock 的用户。
>
> 这份手册只讲“怎么开始用”。先完成一次看行情、添加自选和 AI 分析，再逐步尝试其他功能。

## 先读这一页

go-stock 是一款桌面股票分析工具，可查看 A 股、港股、美股及场内 ETF 行情，并通过 AI 辅助整理信息、分析个股和复盘市场。

请先记住三件事：

1. **软件展示的数据和 AI 回复仅供学习研究，不构成买卖建议。**
2. **AI 需要你自己的模型服务和 API Key 才能工作。** 没有配置 AI 也不影响看行情、管理自选。
3. **不懂的功能先不要打开。** 日常只需从“股票自选”“市场行情”“AI 智能体”“设置”四处开始。

## 1. 安装与首次启动

### 1.1 下载软件

1. 打开项目的 [GitHub Releases](https://github.com/ArvinLovegood/go-stock/releases) 页面。
2. Windows 用户下载 `go-stock-windows-amd64.exe`；macOS 用户下载 `go-stock-darwin-universal`。
3. 下载完成后双击运行。

> Windows 若出现系统安全提示，请确认下载来源确为本项目的 GitHub Releases，再按提示继续。请不要从不明网站下载或运行同名软件。

### 1.2 第一次打开时会发生什么

首次启动时，软件会初始化本地数据并加载股票基础信息。网络较慢时请耐心等待，不要连续重复打开程序。

软件会把你的配置、自选股和本地记录保存在运行目录的 `data` 中。升级或重装前如需保留数据，请先备份这个目录。

### 1.3 建议的初始设置

进入底部导航的 **设置 → 基础设置**，新用户建议：

| 设置项 | 建议 | 原因 |
| --- | --- | --- |
| 启动时更新基础信息 | 开启 | 股票名称、代码等基础数据更完整 |
| 数据刷新间隔 | 保持默认 | 刷新过快会增加网络与电脑负担 |
| 更新通道 | `Release` | 稳定版更适合新用户 |
| 暗黑主题 | 按个人习惯 | 不影响数据与功能 |
| 指数基金 | 想看 ETF 时再开启 | 可让导航保持简洁 |

修改后请点击页面上的 **保存设置**。

## 2. 认识界面

go-stock 的主要导航位于窗口底部。初学阶段只需认识下表中的入口：

| 入口 | 用来做什么 | 何时使用 |
| --- | --- | --- |
| 首页 | 查看概览和常用入口 | 刚打开软件时 |
| 股票自选 | 保存并跟踪你关心的股票 | 每天查看持仓或关注标的时 |
| 市场行情 | 看新闻、行业、资金流、龙虎榜等市场信息 | 想知道今天市场发生了什么时 |
| AI 智能体 | 用自然语言提问，让 AI 调用数据工具协助分析 | 已完成 AI 配置后 |
| 研究中心 | 查看分析报告、异动监控、提示词和交易记录等 | 熟悉基础操作后 |
| 设置 | 配置软件和 AI 模型服务 | 第一次使用或要调整配置时 |

一些菜单可能暂时看不到：例如“基金自选”“AI 智能体”可在设置中启用；部分功能也可能有版本或权限要求。这是正常现象，先使用已显示的基础功能即可。

## 3. 第一次看行情

### 3.1 看市场整体情况

1. 点击 **市场行情**。
2. 先浏览 **市场快讯**，了解当天重要新闻和盘中消息。
3. 再按需要查看 **行业排名**、**板块资金流向** 或 **概念资金流向**。

对于刚入门的用户，建议按下面顺序阅读：

1. 看市场快讯：今天有什么重要消息？
2. 看行业排名：哪些行业涨跌明显？
3. 看板块或概念资金流向：资金更关注哪里？
4. 最后再看龙虎榜、游资动向等较专业页面。

### 3.2 看一只股票

在 **股票自选** 页面底部的搜索框中，输入股票名称、代码或指数关键词，选择结果即可查看。

常见代码格式示例：

| 市场 | 示例 |
| --- | --- |
| A 股 | `600519`（贵州茅台） |
| 港股 | `00700.HK`（腾讯控股） |
| 美股 | `AAPL.US`（苹果） |

打开股票卡片后，先只看四项信息：**当前价格、涨跌幅、最高/最低价、开盘价**。不要急于根据单一数字作出判断。

## 4. 建立自选股列表

自选股就是你长期关注的一组股票。建议先只添加 5 到 10 只，避免列表过长而无法持续跟踪。

### 4.1 添加股票

1. 进入 **股票自选**。
2. 在底部搜索框输入股票名称或代码。
3. 从匹配结果中选择股票，并执行关注/添加操作。
4. 回到“全部”页签，确认它已出现在列表中。

### 4.2 使用分组和概念标签

当自选股增多后，使用两种整理方式：

| 方法 | 示例 | 适合解决的问题 |
| --- | --- | --- |
| 分组 | 持仓、长期观察、短线观察 | 这只股票属于我的哪类关注？ |
| 概念标签 | AI、半导体、高股息 | 它属于什么主题或行业？ |

建议从一个简单分组开始，例如“长期观察”。等能稳定使用一周后，再增加“持仓”“短线观察”等分组。

### 4.3 记录持仓成本（可选）

如果你已经持有某只股票，可在该股票卡片上点击 **成本**，填写持仓数量和成本价。软件会据此显示盈亏信息。

请只记录自己的真实数据，并注意电脑与本地数据文件的安全；这些信息不应作为投资建议的依据。

## 5. 配置 AI 并完成第一次提问

### 5.1 准备 API Key

AI 功能需要从模型服务商获取 API Key。你可以使用 DeepSeek、智谱 AI、阿里云百炼、火山引擎、OpenAI、Ollama 等兼容 OpenAI API 格式的平台。

API Key 类似密码，请遵守以下原则：

- 只从服务商官方控制台获取；
- 不要把 API Key 发到群聊、截图或提交到代码仓库；
- 发现泄露后立即到服务商后台禁用并重新创建；
- 留意服务商的余额、额度和计费规则。

### 5.2 添加一个 AI 模型

1. 进入 **设置 → AI 模型服务**。
2. 新增一条模型配置。
3. 按服务商文档填写名称、接口地址、API Key 和模型名称。
4. 保存配置。
5. 回到 **设置 → 基础设置**，确认 AI 分析功能已启用并保存。

名称可以写成便于识别的形式，例如“DeepSeek 日常分析”。接口地址、模型名称必须以服务商官方文档为准；不要从陌生教程复制地址或密钥。

### 5.3 打开 AI 智能体

完成配置后，点击底部导航的 **AI 智能体**；也可以通过页面右侧的悬浮 AI 助手快速发起对话。

在输入区完成三件事：

1. 选择刚刚创建的模型；
2. 第一次使用时选择 **自动选择** 或 **快速模式**；
3. 用一段完整的话说明你想了解什么。

### 5.4 推荐的第一次提问

直接复制一条即可：

```text
请用通俗的话总结今天 A 股市场的主要热点、上涨和下跌较明显的行业，并列出我还需要留意的风险。
```

```text
请分析贵州茅台（600519）近期的价格表现、资金流向和相关新闻；请把事实、你的推测和风险提示分开写。
```

```text
我是新手。请解释“市盈率、成交量、资金流向”分别是什么，并告诉我看股票时如何避免只凭一个指标下结论。
```

AI 的回答应当被视为待核实的信息整理，而不是交易指令。看到具体价格、预测或推荐时，请回到行情、公告和公开资料自行核对。

### 5.5 想让 AI 看图片时

只有模型本身支持视觉理解，且你在模型配置中打开了 **视觉理解** 开关，图片按钮才可用。可上传本地图片、粘贴截图或添加图片链接。

本地图片可能会经公共图床转为链接后发送。请先遮住账户、持仓成本、手机号、身份证件等敏感信息；单张图片不超过 8MB，一次最多发送 10 张。

## 6. 小白最常用的三个场景

### 场景一：每天 10 分钟了解市场

1. 打开 **市场行情 → 市场快讯**。
2. 查看 **行业排名** 和 **板块资金流向**。
3. 打开自己的 **股票自选**，确认关注股票的涨跌和公告。
4. 若信息较多，再问 AI：“请帮我归纳今天市场最值得继续关注的三条信息，并提示不确定之处。”

目标是建立信息习惯，不是每天都做交易。

### 场景二：研究一只已经关注的股票

1. 在 **股票自选** 中打开目标股票。
2. 查看日 K、分时、资金、公告、研报等信息。
3. 记录你看到的事实，例如“近几日成交量放大”或“公司发布了公告”。
4. 让 AI 解释这些信息之间可能的关系，并要求列出风险和待验证事项。

可使用下面的提问：

```text
请根据这只股票近期 K 线、成交量、资金流向、公告和新闻，做一份新手能看懂的观察清单。不要给买卖指令；请标出需要我自行核实的信息。
```

### 场景三：复盘自己的观察过程

1. 到 **研究中心 → 交易日志(beta)** 记录实际操作或观察理由。
2. 到 **复盘策略 → 每日复盘** 查看市场总结。
3. 记录“当时为什么关注、后来发生了什么、下次如何改进”。

先记录再复盘，比频繁更换指标更容易积累经验。

## 7. 第二周再尝试的功能

熟悉基础流程后，可按以下顺序逐步学习：

| 功能 | 入口 | 建议用途 |
| --- | --- | --- |
| 异动监控 | 研究中心 → 异动监控 | 了解盘中异常波动，不把提示直接等同于机会 |
| 每日复盘 | 复盘策略 → 每日复盘 | 回顾当日市场结构和热点变化 |
| 盘前策略 | 复盘策略 → 盘前策略 | 提前写好观察重点和风险边界 |
| 提示词模板 | 研究中心 → 提示词模板 | 保存自己常用的 AI 提问方式 |
| 提示词回测(beta) | 复盘策略 → 提示词回测(beta) | 比较不同提示词的历史输出，注意历史结果不代表未来 |
| K 线分析 | 底部导航 → K线分析 | 熟悉指标和绘图工具，部分功能可能需要相应权限 |
| 定时任务、飞书/钉钉 | 研究中心 → 定时任务；设置中配置 | 确认基础流程稳定后再开启通知，避免信息过载 |

MCP 服务、技能管理、知识库管理、长期记忆等属于进阶功能。它们适合已有明确工作流的用户，不建议在第一周配置。

## 8. 常见问题与排查

### Q1：为什么 AI 模型下拉列表为空？

进入 **设置 → AI 模型服务**，确认至少有一条已保存的模型配置；再回到基础设置确认 AI 功能已启用并保存。若仍为空，重启软件后检查一次。

### Q2：AI 回复报错或一直没有结果怎么办？

按顺序检查：

1. API Key 是否正确、是否已过期；
2. 接口地址和模型名称是否与服务商官方文档一致；
3. 服务商账户是否有可用余额、额度或网络访问权限；
4. 简化问题后重试，例如先只查询单只股票；
5. 查看软件日志或服务商控制台的错误信息。

不要把 API Key 贴到公开讨论区寻求排查帮助。

### Q3：为什么没有某个菜单或功能？

部分功能需要先在设置中开启，例如 AI 智能体和基金自选；另有部分功能受版本、系统或权益限制。请先更新到正式版，再查看功能页内的提示。

### Q4：行情数据与其他平台不一样，是否出错？

不同数据源的刷新频率、复权方式、交易时段和字段定义可能不同。重要数字请交叉核对交易所公告、上市公司公告或可靠行情来源。

### Q5：如何安全升级或重装？

升级前退出软件并备份运行目录的 `data` 文件夹。下载新版后再安装或替换程序文件。若发现数据异常，可用备份恢复。
